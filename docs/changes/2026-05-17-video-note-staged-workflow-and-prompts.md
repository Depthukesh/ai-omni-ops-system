# 2026-05-17 视频笔记三阶段工作流与提示词分类

## 背景

旧版视频笔记仍是“一次提交同步跑完”的单段链路，创建弹窗里还保留了多余的时长和“输出视频提示词”选项，也无法在故事板生成后停下来让用户修改提示词并继续生成短视频。

同时，视频相关提示词在前后台技能中心里仍聚合成单条展示，不符合“按业务阶段拆开查看和修改”的要求。

## 本次实现

### 1. 视频笔记改为三阶段任务化工作流

- 视频类型收口为 `品牌宣传视频 / 口播带货视频 / 短剧带货视频 / 复刻视频`
- 视频时长只保留 `10 秒 / 15 秒`
- 删除“输出视频提示词”字段
- 新增素材库下拉，只显示素材库中的视频素材；`复刻视频` 强制要求选择素材
- 创建后先进入：
  1. 第 1 阶段：生成创意剧本
  2. 第 2 阶段：生成故事板提示词并调用 `gpt-image-2` 出故事板图片
  3. 第 3 阶段：用户确认后再调用所选视频模型生成最终短视频

### 2. 中间产物持久化到作品主记录

- 视频作品主记录继续使用 `MediaAsset.metadataJson`
- 新增持久化字段：
  - `videoKind`
  - `workflowStage`
  - `creativeScript`
  - `storyboardPrompt`
  - `storyboardImageUrl`
  - `progressSteps`
  - `storyboardRevisions`
  - `materialId / materialTitle / materialVideoUrl`
- 用户离开页面后再次进入，仍可在作品区查看阶段状态、故事板提示词、故事板图片和最终短视频

### 3. 前端作品区改成“卡片列表 + 阶段详情面板”

- 视频作品卡新增阶段徽标和视频类型展示
- 点击作品卡可在工作区右侧/下方查看详情
- 故事板阶段完成后，详情区展示：
  - 创意剧本
  - 可编辑的故事板提示词
  - 故事板图片
  - `修改 / 生成短视频` 两个动作按钮
- 故事板修改后会重新提交第 2 阶段任务；继续生成则进入第 3 阶段

### 4. 视频提示词注册改为按阶段拆分

- 新增并注册 6 条视频提示词：
  - `视频笔记-品牌宣传剧本`
  - `视频笔记-口播带货剧本`
  - `视频笔记-短剧带货剧本`
  - `视频笔记-复刻视频拆解`
  - `视频笔记-故事板提示词`
  - `视频笔记-短视频提示词`
- 后台技能中心目录树改为按“剧本策划 / 视频生成”分组显示
- 前后台技能中心都通过同一组 `promptId` 绑定，继续支持平台基线 + 用户覆盖的修改方式

## 影响范围

- 后端：`WorksModule` 视频任务编排、作品元数据、故事板重生成接口、继续生成短视频接口
- 前端：`/xiaohongshu` 视频创建弹窗、作品卡、详情面板、故事板编辑态、阶段动作
- 技能中心：提示词注册表、mock seed、后台技能树
