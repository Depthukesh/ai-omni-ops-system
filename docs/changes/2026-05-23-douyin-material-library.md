# 2026-05-23 抖音素材库

## 背景

- 抖音工作台原先只有“营销策划方案”分区，没有承接品牌增长策略中的对标作品沉淀。
- 品牌增长策略中的“收集数据 -> 抖音 -> 对标作品信息及数据”也缺少把作品沉淀到抖音素材库的入口。

## 变更

- 在“品牌增长策略 -> 收集数据 -> 抖音 -> 对标作品信息及数据”表格首列新增素材库勾选方框。
- 新增抖音素材库接口，允许将 `DOUYIN_BENCHMARK_WORK` 标记为素材库作品，也允许再次取消加入。
- 抖音工作台新增“素材库”分区，卡片布局与“小红书 -> 素材库”保持一致。
- 抖音素材库数据来源固定为“品牌增长策略 -> 收集数据 -> 抖音 -> 对标作品信息及数据”中被加入素材库的作品。

## 数据口径

- 仅 `DOUYIN_BENCHMARK_WORK` 可加入抖音素材库。
- 素材库状态由采集资产元数据中的 `inMaterialLibrary` 和 `materialAddedAt` 驱动。
- 表格中的素材库勾选方框支持双向切换：勾选时加入素材库，取消勾选时移出素材库。
- 抖音工作台素材库直接过滤抖音采集工作区中的 `benchmarkWorks`。
