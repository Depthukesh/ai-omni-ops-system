# 小红书模板选择器分页与模板裁剪

## 1. 变更背景

- 模板选择弹窗当前一次性展示全部模板，页面过长，用户需要持续向下滚动才能看到 `使用这张模板` 或 `使用所选模板` 按钮。
- 模板卡片虽然支持点击选中，但图片区域缺少直接提示，首次使用时不够直观。
- 用户明确要求把 `夏日出行露营city walk小红书封面` 与 `夏日出行露营city walk小红书封面 / 效果图` 这两组模板从库中移除，并且两个模板入口都采用同一套新交互。

## 2. 本次改动

### 2.1 模板卡片增加点击提示

- `original-reference-template-picker.tsx` 为模板图片增加浮层提示，未选中时显示 `点击选择` 或 `点击多选`，选中后切换为 `已选中`。
- 提示同时带小图标，减少“图片只是预览、不能直接点”的误解。

### 2.2 模板库改为每页 10 张分页

- 模板列表不再一次性渲染全部结果，统一改为每页 `10` 张。
- 新增分页栏，支持：
  - 当前页 / 总页数摘要
  - 上一页 / 下一页
  - 邻近页码快速跳转
- 分类筛选或关键词搜索变化后，分页会自动回到第一页，避免停留在无效页码。

### 2.3 移除 city walk 模板分组

- 导入脚本新增排除规则，默认跳过 `i 夏日出行露营city walk小红书封面` 目录及其子目录。
- 模板生成清单 `xhs-original-reference-templates.generated.ts` 已按新规则重生成：
  - 分类数从 `10` 变为 `8`
  - 模板数从 `274` 变为 `224`
- 由于封面模板和配图模板共用同一个模板清单与选择器，两个入口都会同步移除这两组模板。
- 本次额外执行了原始素材清理：只物理删除本地 `i 夏日出行露营city walk小红书封面/效果图` 目录中的 PNG 素材，并同步清理 OSS 中该 `效果图` 分组的历史对象；顶层封面 JPG 不在本次删除范围内。

## 3. 修改意图

- 用分页而不是继续拉长弹窗，是为了让模板确认按钮始终处于更短的滚动距离内。
- 把点击提示直接覆盖在图片上，是为了让用户在第一眼就知道“点图即可选中”。
- 保留模板资源的 `storageKey` 与站内读取链路不变，只调整模板库可见范围，避免影响已有引用逻辑。

## 4. 影响范围

- 页面：`/xiaohongshu`
- 前端文件：
  - `apps/web/src/app/(dashboard)/xiaohongshu/original-reference-template-picker.tsx`
  - `apps/web/src/styles/globals.css`
- 模板清单与脚本：
  - `apps/server/src/modules/works/xhs-original-reference-templates.generated.ts`
  - `scripts/import-xhs-original-reference-templates.cjs`

## 5. 验证

- 模板清单已重生成，当前为 `8` 个分类、`224` 张模板
- `GetDiagnostics` 将覆盖模板选择器与相关样式文件
- `npm run build:web` 通过后可确认分页与样式代码无构建错误
- `npm run build:server` 通过后可确认模板清单更新未影响后端编译

## 6. 风险与后续

- 本次移除的是模板库可见范围，不主动删除 OSS 中历史对象，避免误删仍可能被其他环境引用的素材。
- 若后续还要继续裁剪模板类别，只需沿用导入脚本中的排除规则并重生成模板清单。
