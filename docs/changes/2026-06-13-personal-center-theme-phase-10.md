# 2026-06-13 个人中心第十批开发：深浅关系与材料语言重设计

## 为什么重做

- 当前首页和 dashboard 顶部已经建立了深色品牌氛围。
- 但 `personal-center` 工作区仍然保留明显的浅色大面板和白色卡片，导致出现“外层黑色、内层浅白”的拼接感。
- 这会让已登录工作台看起来像是从另一个后台模板直接嵌进来的，而不是首页品牌体系的自然延伸。

## 设计目标

- 保留首页已有的深色品牌语言，不改成完全浅色后台。
- 将 `personal-center` 统一成一套“深色母体 + 分层玻璃卡片”的夜间工作台。
- 保留清晰的信息层级，但用更小的亮度差来区分层次，而不是用纯黑和大白块硬切。

## 新的设计思路

### 1. 三层材料系统

- 第一层：`dashboard-layout`
  - 继续保留深色夜景背景，但降低“纯黑硬底”的感觉，改成更柔和的深蓝与微网格。
- 第二层：`personal-center-workspace-shell` / `personal-center-panel`
  - 从原来的浅色大面板改成半透明深色玻璃容器。
  - 让它与顶部导航处于同一材料家族。
- 第三层：`metric-card` / `entity-card` / `light-data-panel`
  - 不再是白卡片，而是比容器稍亮一层的深色内容卡。
  - 用阴影、边线和轻微暖色高光建立层级。

### 2. 统一控件语言

- `tab-button`
  - 默认改成深色半透明 pill
  - 激活态保留金色品牌强调
- `secondary-button`
  - 从浅灰白按钮改成深色半透明按钮
  - 减少和背景冲突
- 表单输入框 / 下拉框 / 表格
  - 全部切换到暗色玻璃表面
  - 提高与整体工作区的一致性

### 3. 文字层级重配

- 标题改成高亮浅色文字
- 说明文字改成低对比的冷灰蓝
- 保留重点数据的亮度优势，让用户还能快速扫到数量和入口

### 4. 状态色重配

- 成功态、处理中、暂停态都改成适配深色背景的半透明状态胶囊
- 避免原本浅背景状态色在暗面板里显得突兀
