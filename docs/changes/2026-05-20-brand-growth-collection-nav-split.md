# 2026-05-20 收集数据导航拆分为独立板块

## 背景

- 原先 `收集数据` 下只有一个 `平台采集` 二级入口。
- 该入口内部同时堆叠了 `飞书配置`、`小红书`、`抖音` 三段内容。
- 实际产品要求是导航级拆分，而不是单页面内分区。

## 本次调整

- 将 `收集数据` 下的二级导航改为：
  - `飞书配置`
  - `小红书`
  - `抖音`
  - `每日热点`
- `飞书配置` 页面只保留飞书应用配置、副本绑定和同步前置设置。
- `小红书` 页面只保留小红书同步按钮与小红书同步结果展示。
- `抖音` 页面只保留抖音同步按钮、字段预览与抖音真实采集结果展示。

## 风险边界

- 不改后端接口。
- 不改数据库 schema。
- 不改现有小红书和抖音数据结构。
- 权限层暂时继续复用原有 `brandGrowth.collection.xiaohongshuCollection` 权限键，只做前端导航和页面挂载拆分。
