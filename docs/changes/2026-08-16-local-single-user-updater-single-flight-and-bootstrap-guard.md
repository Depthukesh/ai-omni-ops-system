# 2026-08-16 local-single-user 升级单飞与启动确认收紧

## 1. 背景

用户反馈另一台笔记本在“版本与升级”页点击【立即升级】后：

- 页面显示“运行中”
- 长时间没有任何 PowerShell 窗口或升级结果反馈
- 过一段时间按钮又能继续点击
- 版本并没有真正更新
- 每点一次，`LOCAL_APP_DATA_ROOT/updates/apply-runs/` 下都会新增一轮目录

这说明当前升级链存在两个体验与可靠性问题：

1. 前端没有阻止 `APPLYING` 阶段重复触发升级
2. 后端在拉起 updater 后，没有确认 updater 是否真的成功启动

## 2. 根因

### 2.1 重复点击没有被拦住

版本页按钮是否可点击，之前只看：

- 当前环境是否支持升级
- 是否存在可用新版本
- 是否已有预下载包

没有把当前升级状态 `APPLYING / DOWNLOADING` 纳入禁用条件。

结果就是：

- 即使上一轮升级还没结束
- 用户仍然可以再次点击【立即升级】
- 每一次都会新建一轮 `apply-runs/<runId>`

### 2.2 升级器启动缺少“已真正起跑”的确认

后端之前的策略是：

- 生成 updater 脚本和 config
- 生成 `.cmd` 包装器
- 调用 `cmd.exe /c run-local-single-user-updater.cmd`
- 只要 spawn 没立即抛错，就直接向前端返回“升级进程已启动”

问题在于：

- 这只能证明“启动命令被发出了”
- 不能证明 PowerShell / updater 脚本真的已经进入执行
- 一旦启动失败或被本机环境拦截，前端只能看到“看起来启动了”，却没有真实失败信号

## 3. 本次改动

### 3.1 后端升级入口改为单飞

文件：

- `apps/server/src/modules/system-update/system-update.service.ts`

新增保护：

- 当持久化状态仍为 `APPLYING` 时，拒绝再次发起新一轮升级
- 对长时间没有新进展的 `APPLYING` 状态做超时收口，自动改写为 `FAILED`

这样可以避免：

- 一台机器同时堆多轮 `apply-runs`
- 用户反复点击后把现场越搞越乱

### 3.2 updater 拉起后必须做启动确认

同一文件中，升级入口现在改为：

- 直接拉起 `powershell.exe`
- 后台静默执行 updater
- 拉起后在短窗口内检查 updater 是否真的开始写：
  - 状态文件
  - trace 日志
  - stdout / stderr 日志

如果在确认窗口内没有任何启动迹象，就直接：

- 把升级状态写成 `FAILED`
- 把失败原因回给前端

这能把“命令发出去了但其实没跑起来”的隐性失败，改成用户能看到的显式失败。

### 3.3 前端升级页禁止重复点击

文件：

- `apps/web/src/app/(dashboard)/personal-center/version/page.tsx`

调整后：

- `DOWNLOADING` / `APPLYING` 阶段禁用【预下载安装包】与【立即升级】
- `APPLYING` 阶段按钮文案显示为“升级进行中...”
- 页面补充提示：
  - 升级在后台静默执行
  - 不会弹出 PowerShell 窗口
  - 不要重复点击

## 4. 影响面检查

### 4.1 受影响范围

- local-single-user 版本升级入口
- local-single-user updater 拉起链路
- 个人中心“版本与升级”页交互

### 4.2 为避免副作用做的保护

- 没有修改升级包下载协议
- 没有修改 SHA256 校验逻辑
- 没有取消失败回滚
- 没有改动本地数据目录、存储目录和数据库目录
- 只是把“重复触发”与“静默启动失败”这两个口子收紧

## 5. 验证

已完成：

- `npm run build:server`
- `npm run build:web`

静态确认：

- `APPLYING` 状态下后端不再接受第二次升级请求
- 前端升级页不再允许用户在 `APPLYING` 阶段重复点击
- updater 启动失败会更早写成 `FAILED`，而不是一直留在“看起来在运行”

## 6. 结论

这次问题不应简单归因于“电脑配置低”。

低配置机器可能会让升级更慢，但之前真正的缺口是：

- 升级中还能重复点击
- 启动失败没有被明确识别和反馈

本次修复后，升级链会更接近“慢可以，但不能无声失败，也不能让用户一顿连点把现场点乱”。
