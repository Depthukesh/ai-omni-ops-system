# 2026-08-16 GEO 第三方媒体投放与软文街平台接入

## 1. 背景

本轮目标是把 GEO 工作台里的 `第三方媒体` 从“只保存文章结果”继续接到真实投放链路。

用户明确要求：

- 阅读并接入 `GEO/软文街API接口文档2.0(2).docx`
- 凭证入口仍放在 `个人中心 -> 第三方接口配置`
- 前端入口放在 `GEO -> 第三方媒体` 下方
- 新增 `第三方媒体投放` 列表，展示可投放媒体
- 每行支持 `立即投放`
- 点击后从当前 `第三方媒体` 已生成文章里选一篇，直接提交投放

## 2. 本次改动

### 2.1 软文街平台种子接入

- 在 `third-party-platform-catalog` 中新增：
  - `platform_https_api_kol_cn`
  - 名称：`软文街平台`
  - Base URL：`https://api.kol.cn`
- 说明文案明确：
  - 当前品牌 Owner 在个人中心填写 `API Key + 登录账号 + 登录密码`
  - 文档中的 `identity / captcha_token / captcha` 由后端按示例固定补 `advertiser`

### 2.2 后端投放服务

- 新增 `RuanwenjieMediaService`
  - 负责获取 token
  - 拉取软文资源列表
  - 提交投放订单
  - 当资源接口或订单接口返回 `401` 时自动刷新 token 并重试一次
- 当前品牌共享凭证仍复用 `BrandThirdPartyPlatformSecret.apiKey`
  - 对软文街改为保存结构化 JSON 字符串
  - 没有新增数据库表，也没有改变现有第三方平台配置总入口

### 2.3 GEO 工作台新增投放区

- 在 `/geo` 的 `第三方媒体` 板块下新增一个独立卡片：
  - 标题：`第三方媒体投放`
- 列表字段包含：
  - 媒体名称
  - 平台
  - 分类
  - 地区
  - 价格
  - 刊发时效
  - 成功率
  - 收录率
  - 案例
  - 操作
- 每行支持：
  - `查看案例`
  - `立即投放`

### 2.4 立即投放弹窗

- 点击 `立即投放` 后打开弹窗
- 弹窗里直接读取当前 GEO `third_party_media` 真源文章
- 用户选择文章后，后端会校验：
  - 当前文章确实属于该品牌
  - 内容类型确实是 `third_party_media`
  - 已保存 HTML 内容
- 校验通过后再提交软文街订单

### 2.5 个人中心平台专属配置

- `个人中心 -> 第三方接口配置` 保持原页面结构不变
- 只对 `软文街平台` 显示平台专属字段：
  - `软文街 API Key`
  - `登录账号`
  - `登录密码`
- 其它平台仍维持原来的单字段配置，不一起改复杂

## 3. 影响面检查

### 3.1 受影响范围

- 个人中心第三方接口配置页
- 第三方平台种子与品牌共享凭证解析
- GEO 工作台 `第三方媒体` 板块
- OpenClaw GEO 内容真源读取链路

### 3.2 为避免副作用做的保护

- 没有改动已有 GEO 文章真源 `OpenClawGeoContent`
- 没有新建投放记录表，也没有更改现有 GEO 文章保存结构
- 软文街专属字段只对该平台显示，其它平台仍保持原有体验
- 品牌共享凭证仍复用现有 `BrandThirdPartyPlatformSecret`，避免把整个第三方平台体系一并迁移
