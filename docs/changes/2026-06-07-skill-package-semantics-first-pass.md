# 2026-06-07 Skill Package Semantics First Pass

## 背景

- 现有后台“技能中心”中，能力包与技能的职责边界仍有混用。
- 需要统一成新的产品语义：
  - 技能：主要功能实现单元
  - 能力包：系统里的最小功能实现单元，但本质上是多个技能按顺序编排后的组合容器

## 本次语义收口

### 1. 技能

- 技能被定义为具体功能执行单元。
- 一个技能内部重点围绕 3 个维度组织：
  - 输入项
  - 提示词及其他元素
  - 输出

### 2. 能力包

- 能力包不再承担技能级 Prompt、References、Scripts、Knowledge、Version 的管理职责。
- 能力包当前只保留：
  - 基础信息
  - 技能编排顺序
- 能力包页面不再突出版本管理，符合“能力包无需版本管理”的产品约束。

## 后台页面调整

### 能力包摘要

- 仅保留能力包本体字段与技能编排顺序。
- 列表表头改为偏编排视角：
  - 能力包
  - 模块
  - 技能编排数
  - 状态
  - 作用域
  - 更新时间

### 技能专区

- 保留左侧技能目录与右侧技能维护区。
- 右侧技能维护区按 3 个维度重组：
  - 输入项
  - 提示词及其他元素
  - 输出
- 本轮继续把技能说明做成 first pass 的结构化编辑：
  - 技能说明前言
  - 步骤摘要
  - 输入项草稿
  - 输出项草稿
- 保存时前端会将这 4 段内容重新合成为现有 `SkillConfig.description`，确保不改数据库结构也能先把交互语义收口。
- 本轮继续把技能专区中的 `References / Scripts` 从占位说明推进到真实展示：
  - 如果技能已绑定能力包，技能页会按所属能力包按需读取真实资产
  - 直接展示当前技能可复用的 `References` 与 `Scripts` 列表
  - 仍保持能力包作为当前资产真源，避免影响现有资产管理入口
- 本轮继续把“继承展示”推进到“技能级可选绑定 first pass”：
  - 技能默认继承所属能力包中的全部 `References / Scripts`
  - 管理员可以在技能页勾选出当前技能真正需要的资产子集
  - 选择结果暂时不新建数据库表，而是跟随技能说明一起持久化到 `SkillConfig.description`
- 本轮继续把“输入项”从单个说明框推进到结构化配置：
  - 数据库参数：支持新增多条，并区分“是否植入”和“下拉框选择”两种形式
  - 知识库参数：支持新增多条，当前先选择知识库来源，具体内容选择器待知识库内容模型接入
  - 自定义输入参数：支持新增多条，并区分下拉框、输入框、文件上传三种形式
- 本轮继续提升输入项的后台录入效率：
  - 数据库参数、自定义输入参数支持一键补齐常用项
  - 数据库参数、知识库参数、自定义输入参数都支持整组清空
  - 三类输入项都提供实时摘要，方便快速检查当前技能输入配置
- 本轮继续把“数据库参数”从静态文案推进到真实同步：
  - 植入参数与下拉参数的命名、字段标签统一调整为数据库语义
  - 植入参数会同步品牌资料、产品资料、营销策划方案等现有数据库内容数量
  - 下拉参数会同步营销日历、选题库、素材库的真实可选项，并自动提供“不植入”选项
  - 数据库参数操作按钮改成横排展示，避免后台录入区纵向折行
- 本轮继续把“知识库参数”推进成真实选择器：
  - 直接复用现有知识库与知识库文件数据，按知识库展示已同步内容数量
  - 每条知识库参数支持先选择知识库，再选择该知识库下已同步的具体内容
  - 具体内容选择器默认提供“整库检索”选项，未指定具体内容时按整个知识库参与检索
  - 知识库参数操作按钮改成横排展示，并在摘要区显示各知识库已同步内容数量
- 以上输入项配置本轮仍采用 first pass 策略：
  - 不新建输入项数据库表
  - 先跟随技能说明一起持久化到 `SkillConfig.description`

## 当前实现边界

- 本次属于 first pass 语义重构，优先修正页面职责和操作入口。
- `References`、`Scripts`、知识库选择目前仍有继承型 / 预留型逻辑：
  - 页面上已经进入技能维度表达
  - 真正的技能级真源对象仍需后续继续落库
- 当前“输入项 / 输出”仍是结构化文本编辑，不是独立表结构；这样可以在不影响现有功能的前提下，先把后台维护方式调整到新的技能语义。

## 后续建议

- 为技能新增专用真源对象：
  - SkillInputSchema
  - SkillReferenceAsset
  - SkillScriptAsset
  - SkillOutputSchema
- 将“上游输出 -> 下游输入”的链路从展示逻辑升级为显式关系定义。
