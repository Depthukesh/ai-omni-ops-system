# 2026-06-13 个人中心第七批上线：运营页面文案与状态层级收口

## 为什么改

- 第六批已经补齐了 `skills`、`third-party-platforms`、`openclaw` 三页的引导闭环。
- 个人中心里仍有几页保留了较强的研发调试口吻，例如直接展示状态码、技术术语较重、空态动作不够明确。
- 本批继续只处理 `personal-center` 范围内的前端表达层，不调整接口、权限和业务流程。

## 本次范围

- `apps/web/src/app/(dashboard)/personal-center/tasks/page.tsx`
- `apps/web/src/app/(dashboard)/personal-center/orders/page.tsx`
- `apps/web/src/app/(dashboard)/personal-center/security/page.tsx`

## 本次改动

### 1. 任务中心

- 将顶部说明改成更贴近运营视角的表达，强调“查看进度、失败重试、人工取消”。
- 把卡片内原本直接显示的英文状态码改成中文状态标签。
- 修复残余乱码字段，如“最终使用模型”“执行失败”。
- 新增上下文说明条，帮助用户先关注运行中和失败任务，再决定是否人工介入。
- 搜索区增加“清空搜索”操作，空结果时提供明确返回动作。

### 2. 订单中心

- 将顶部说明从“统一账单入口”改成更直观的“核对消费、补单进度和充值情况”。
- 顶部新增筛选引导，明确“先看状态，再看订单类型”。
- 订单卡片里把原始订单状态改成中文标签展示。
- 搜索区增加“清空搜索”，空态支持一键恢复全部筛选或直接去创建订单。
- 清理品牌下拉和订单副标题中的不自然分隔文案。

### 3. 安全设置

- 将“Token 持有状态”等研发术语改成运营用户更容易理解的“登录凭证状态”“续期凭证状态”。
- 顶部增加上下文说明条，明确“资料维护”和“安全检查”的先后处理路径。
- 将若干说明文案改为更自然的用户口吻，减少接口实现细节直接暴露。
- 保留已有功能和信息密度，但让页面更像账号中心，而不是调试快照页。

## 明确不改的内容

- 不修改登录逻辑、Token 处理机制、品牌切换逻辑和接口协议。
- 不增加新依赖，不引入复杂动画。
- 不增加服务器请求负担。
