# 2026-06-13 品牌增长报告营销日历月历化改版

## 背景

用户要求将“品牌增长策略 -> 品牌增长报告 -> 营销日历”从原来的未来 7 天卡片，调整为参考图风格的整月月历视图，并满足以下交互与视觉要求：

- 左上角通过左右箭头切换全年月份
- 右上角仅保留“公历节日”和“节气”两个切换按钮
- 每个日期格显示公历日期和农历日期
- 当天日期有高亮底色
- 法定节假日显示“休”标识
- 跨月补位日期整体弱化显示
- 删除用户打叉的旧摘要区域

## 本次改动

### 1. 营销日历数据层升级

文件：

- `apps/web/src/app/(dashboard)/xiaohongshu/calendar-helpers.ts`

改动：

- 新增 `CalendarMonthCell`，统一承载月历单元格所需的数据
- 将 `buildCalendarMonthMatrix()` 重构为固定 42 格月历矩阵
- 为每个日期补充：
  - 公历日期
  - 农历日期
  - 节气
  - 公历节日
  - 法定休假标记
  - 对应营销日历选题
- 补充一批常用公历节日映射，如儿童节、受侵略戕害的无辜儿童国际日、世界环境日、教师节等
- 按 2026 年法定节假日安排补充休假日期范围，用于显示“休”标识

### 2. 营销日历界面重做为整月月历

文件：

- `apps/web/src/app/(dashboard)/xiaohongshu/calendar-workspace.tsx`

改动：

- 删除旧的未来 7 天摘要型展示区域
- 新增当前可见月份状态 `visibleMonthKey`
- 新增左右箭头切换月份逻辑
- 新增“公历节日”和“节气”两个显隐开关
- 月历单元格支持：
  - 日期点击打开当天营销内容详情
  - 法定节假日“休”徽标
  - 当天高亮
  - 跨月日期弱化
  - 无内容时保留统一占位结构
- 将旧的“生成接下来 7 天”文案改为“生成营销日历 / 重新生成日历”

### 3. 视觉样式统一到品牌增长策略暗色体系

文件：

- `apps/web/src/styles/globals.css`

改动：

- 新增月历容器、工具条、筛选按钮、日期格、节日标签、节气标签、休假徽标等样式
- 月历主体采用品牌增长策略同体系的暗色玻璃卡片语言
- 优化状态层级：
  - 当天高亮
  - 法定休假暖色提醒
  - 选中态边框强调
  - 跨月日期内容降低透明度
- 为较窄视口增加横向滚动兜底，保证 7 列月历结构不塌陷

### 4. 复用挂载处同步收口

文件：

- `apps/web/src/app/(dashboard)/brand-growth/workspace.tsx`

改动：

- 移除 `CalendarWorkspace` 已不再使用的旧格式化参数，避免遗留旧 7 天视图语义
