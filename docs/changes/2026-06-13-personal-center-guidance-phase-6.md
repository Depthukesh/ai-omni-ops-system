# 2026-06-13 个人中心第六批上线：引导闭环与操作层级收口

## 为什么改

- 前几批已经完成个人中心的壳层、文案修复、视觉基线和移动端表格收口。
- 剩余问题主要集中在操作信息闭环上：部分页面空态只说明“没有内容”，但没有告诉用户下一步怎么做；部分编辑页按钮主次关系还不够明确。
- 本批继续只处理 `personal-center` 范围内的设计层，不改业务流程，不增加接口负担。

## 本次范围

- `apps/web/src/app/(dashboard)/personal-center/third-party-platforms/page.tsx`
- `apps/web/src/app/(dashboard)/personal-center/skills/page.tsx`
- `apps/web/src/app/(dashboard)/personal-center/openclaw/page.tsx`
- `apps/web/src/styles/globals.css`

## 这次改了什么

### 1. 第三方接口配置页

- 把平台详情区改成“当前查看对象 + 权限说明 + 主次操作”的结构，先说明当前在维护哪个平台，再给保存、打开平台、打开文档动作。
- 把无权限提示从大块空态改成更轻的上下文提示，避免打断阅读。
- 把“无匹配平台”和“未选择平台”改成带按钮的引导空态，支持直接清空搜索或返回概览。
- 详情区中的平台链接与说明文档改为更稳定的文本展示，减少重复按钮。

### 2. 技能中心页

- 修复残余乱码标签，将 `妯″瀷` 改回正常的“模型”。
- 给详情区补充“当前正在编辑什么、是否有未保存修改、是否有权限保存”的说明条。
- 在搜索为空、未选择提示词时补充明确动作，支持直接清空搜索或返回概览。
- 顶部搜索区补上“清空搜索”操作，减少来回删除输入。

### 3. OpenClaw 安装页

- 在页面上方增加安装路径说明，明确“生成令牌 -> 复制 MCP 配置 -> 下载 Skill ZIP”的顺序。
- 为 MCP 地址和完整安装令牌补充直接复制动作，减少用户在多个区域来回查找。
- 把一次性令牌提示改成更明确的提醒区，并提供“立即复制完整令牌”和“查看/隐藏完整令牌”操作。
- MCP 安装配置卡片中补充令牌可见性切换，让复制片段和查看令牌形成一个闭环。

### 4. 复用样式层

- 新增 `personal-split-layout`、`personal-context-banner`、`personal-context-actions`、`personal-inline-hint` 等轻量样式。
- 统一空态中的标题、说明文案和按钮区域表现。
- 在移动端为新的分栏和引导条补充响应式收口，保证小屏下仍是单列阅读。

## 明确不改的内容

- 不改登录逻辑、权限逻辑、接口协议和数据库结构。
- 不新增接口请求，不增加服务器负担。
- 不引入新依赖，不增加复杂动画。
