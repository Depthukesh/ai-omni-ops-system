# 2026-09-11 抖音竞品作品逐账号提交修正

## 背景

用户反馈 `品牌增长策略 -> 收集数据 -> 抖音 -> 竞品作品信息及数据` 当前有两个交互问题：

1. 已绑定竞品账号在“作品源”列表里没有展示账号名称，只显示账号 locator。
2. 作品采集仍然只有顶部整批提交，无法按单个竞品账号逐条提交采集作品。

这会让用户难以确认“当前这行到底是哪个账号”，也无法按账号逐个控制采集节奏。

## 本次修正

### 1. 竞品作品源列表补回账号名称

- 当前行级列表会先用已同步的竞品账号结果匹配绑定 entry。
- 匹配成功后，列表会在 locator 上方直接显示 `accountName`。
- 这样用户在 `竞品作品信息及数据` 卡片里就能直接看到每个竞品账号的名称和对应 locator。

### 2. 竞品作品改为按账号逐条提交

- 去掉 `竞品作品信息及数据` 卡片顶部原来的整批“提交”按钮。
- 每个竞品账号行尾新增独立 `提交` 按钮。
- 点击后仅针对当前这一个账号发起 `scope=competitorWorks` 采集，不再把整个账号列表一起提交。

### 3. MCP / Skill 同步口径

- 本次没有新增或修改 MCP 工具、Skill 路由，也没有改后端接口协议。
- 当前只是把已有 `collectors/douyin` 的 `scope=competitorWorks` 能力重新接回到正确的前端交互。
- 因此 MCP / Skill 无需改 schema，只需保持与现有接口说明一致。

## 影响范围

- 页面：
  - `品牌增长策略 -> 收集数据 -> 抖音 -> 竞品作品信息及数据`
- 前端文件：
  - `apps/web/src/app/(dashboard)/brand-growth/collection-workspace.tsx`
  - `apps/web/src/app/(dashboard)/brand-growth/workspace.tsx`

## 验证

- 前端静态检查 / 构建验证待本次代码合并后一并执行。

## 结果

- 竞品作品采集源列表现在能直接看到账号名称。
- 竞品作品采集现在按账号逐条提交，不再强制整批一起采集。
