# 2026-08-10 个人中心技能中心恢复按技能展示

## 背景

用户反馈本地单机版 `个人中心 -> 技能中心` 虽然已经恢复可加载，但页面里的展示内容和之前网页版本差异很大，看起来不像“按技能维护”，而是被拆成了很多细项。

## 根因

`apps/web/src/app/(dashboard)/personal-center/skills/page.tsx`

此前已经在 `2026-05-17` 被改成“按提示词叶子项编辑”的口径：

- 左侧列表按分类树 + prompt leaf 展开
- 右侧一次只编辑一个 prompt leaf
- 页面统计口径也变成“技能项 / 提示词项”

这套结构虽然更细，但和用户已经习惯的网页版“左侧按技能列表、右侧查看该技能下全部提示词”的体验不一致，因此在本地单机版恢复后看起来像“内容完全不一样了”。

## 本次调整

文件：

- `apps/web/src/app/(dashboard)/personal-center/skills/page.tsx`

调整内容：

1. 恢复为按技能展示：
   - 左侧展示技能列表
   - 右侧展示当前技能详情与该技能下全部提示词
2. 保留当前品牌共享覆盖语义，不退回早期“个人私有覆盖”文案
3. 保留当前模型下拉与品牌权限判断：
   - 品牌管理员可编辑
   - 非管理员只读查看
4. 保留当前真实后端数据接口，不改 `user-skills` 返回结构

## 影响范围

- `apps/web/src/app/(dashboard)/personal-center/skills/page.tsx`
- `docs/changes/2026-08-10-personal-center-skill-page-restore-skill-view.md`

不影响：

- `user-skills` 后端接口
- SQLite 兼容修复
- 技能 / 提示词实际数据内容
- OpenClaw 与升级链

## 验证

已计划：

- 执行 `npm --workspace apps/web run build`
- 重新打开 `个人中心 -> 技能中心`
- 确认页面恢复为“左侧技能列表 / 右侧技能详情 + 提示词列表”

## 结论

这次不是技能数据错了，而是前端页面后来切到了更细的“提示词叶子项”视角。现在把个人中心技能中心恢复到更接近原网页版的“按技能查看与编辑”口径，同时继续保留当前品牌共享覆盖和模型配置能力。
