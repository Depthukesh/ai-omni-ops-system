# 2026-05-21 抖音对标作品表格展示细化

## 背景

- 用户在线上验证“对标作品信息及数据”时，发现展示层还有几个问题：
  - 播放量未返回时被误显示为 `0`
  - 表格内长内容超出范围时不够紧凑
  - 部分长值不方便复制
  - 作品时长仍以毫秒展示
  - 对标作品表格上方保留了一段冗余字段说明

## 本次调整

- 播放量、作者粉丝数、作者总获赞等可选统计值在缺失时显示为 `-`，避免误判为真实零值
- 表格单元格统一支持自动换行
- `作品 ID`、`作者抖音号` 等长值支持点击复制
- 作品时长从毫秒改为秒显示
- 删除“对标作品信息及数据”表格上方冗余字段说明

## 影响文件

- `apps/web/src/app/(dashboard)/brand-growth/collection-workspace.tsx`
- `apps/web/src/styles/globals.css`
