# 2026-05-21 小红书工作区读取失败与图片超时报错澄清

## 背景

- 员工账号在小红书工作区顶部看到“品牌增长报告读取失败”“半年营销规划读取失败”，但管理员确认这两类数据在系统中已经存在。
- 原创笔记图片生成时报错 `gpt-image-2 请求失败：524`，用户需要区分这是权限问题、配置问题还是上游服务超时。

## 本次调整

### 1. 小红书工作区读取提示细化

- 对品牌增长报告、半年营销规划、小红书营销策划方案、营销日历的读取失败提示增加失败原因分流：
  - 若后端返回“当前账号没有该板块的查看权限”，前端显示为“无查看权限”
  - 若后端返回“当前账号无权访问该品牌”，前端显示为“所属品牌无访问权限”
  - 其他情况继续显示真实错误消息

### 2. 原创笔记图片失败提示细化

- 对图片生成阶段的上游错误做统一归一化：
  - 若错误包含 `524` / `timeout occurred` / `Cloudflare`
  - 前端最终会看到“上游图片接口超时（524）”
- 这样可以和“Provider 未激活 / 私钥缺失 / 配置读取失败”区分开

### 3. 二创笔记与参考图失败定位增强

- 统一图片生成函数此前把失败文案写死为“原创笔记图片生成失败”，会导致二创笔记和视频故事板链路误报。
- 现在按真实业务链路返回对应标签：
  - `原创笔记图片生成失败`
  - `二创笔记图片生成失败`
  - `视频故事板图片生成失败`
- 当上游返回 `image upload failed` 这类错误时，异常信息会附带参考图上下文摘要，便于快速判断是素材库作品图、产品图还是上传文件触发了失败。

## 影响文件

- `apps/web/src/app/(dashboard)/xiaohongshu/use-xiaohongshu-workspace-loader.ts`
- `apps/server/src/modules/works/works.service.ts`

## 验证建议

- 使用仅有小红书工作区权限、但没有品牌增长报告查看权限的员工账号进入页面，确认顶部提示改为“无查看权限”
- 触发一次图片生成超时场景，确认错误提示明确出现“上游图片接口超时（524）”
- 在二创笔记里触发一次图片上传失败场景，确认错误文案显示为“二创笔记图片生成失败”，且附带参考图 URL 或上传文件摘要
