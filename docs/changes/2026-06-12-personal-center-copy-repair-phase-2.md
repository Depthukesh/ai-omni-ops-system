# 2026-06-12 个人中心第二批上线：协作、邀请、第三方平台、技能中心文案修复

## 为什么改

- 个人中心多个二级页已经接入功能，但仍有大量中文乱码和不完整文案，影响正常使用。
- 这一批优先修复用户高频入口的可读性问题，让页面先达到可上线、可理解、可继续迭代的状态。
- 继续遵守两个边界：不影响现有功能，不增加服务器负担。

## 这次改了什么

### 1. 团队协作页

- 修复页头、状态提示、成员管理、邀请链接、权限设置、审计日志等区域的中文乱码。
- 将角色、成员状态、按钮、空态与提示语统一为可读中文。
- 保留成员管理、权限保存、主账号转移、邀请接受等原有业务逻辑。

### 2. 第三方平台页

- 修复平台列表、平台详情、API Key、蝉镜凭证、动态统计、说明文档等区域文案。
- 将状态标签、空态、搜索提示、品牌上下文说明统一为清晰中文。
- 不改平台配置接口，只修复前端展示和说明。

### 3. 邀请通知中心

- 修复筛选条、统计卡、待处理邀请、邀请总览、分页按钮与未读状态文案。
- 保留接受邀请、标记已读、恢复未读、复制筛选链接等行为不变。

### 4. 技能中心

- 修复搜索区、品牌状态说明、左侧分组树、提示词编辑区、保存与重置按钮等主文案。
- 保留技能保存、重置平台基线、模型选择、提示词内容编辑等功能不变。

## 明确不改的内容

- 不改登录、鉴权、权限判定、接口协议和数据库结构。
- 不新增额外请求，不增加后端计算或服务常驻负担。
- 不引入大图、重动画或会增加前端运行成本的视觉效果。
