# 原创笔记界面收口与卡片交互优化

## 1. 变更背景

- 原创笔记已能生成作品，但页面仍保留了偏“详情面板”式的旧展示方式
- 用户明确要求：
- 顶部标题改成“原创笔记工作区”
- 作品卡片支持左右切换图片并点击放大预览
- 点击编辑后改为弹窗编辑标题和正文
- 删除作品卡片下方整块详情内容

## 2. 变更目标

- 让原创笔记分区的页面定位、交互方式和信息密度更符合“作品工作区”形态
- 收掉多余详情区，只保留卡片流、状态区和弹窗交互

## 3. 修改内容

### 3.1 前端

- 将原创笔记分区页头改为“原创笔记工作区”，并同步更新副文案
- 原创作品卡片接入图片轮播逻辑，支持左右切换查看封面和配图
- 点击卡片中的当前图片时，复用现有图片灯箱进行放大预览
- 将原创笔记编辑交互改为弹窗形式，支持修改标题和正文
- 删除卡片列表下方的原创笔记详情大面板

### 3.2 后端

- 无后端接口结构改动

## 4. 修改意图

- 收掉页面下半部分的大面板，是为了让原创笔记区域回到“作品浏览和管理”主场景
- 编辑改用弹窗，是为了减少页面跳跃和长内容堆叠
- 图片轮播和放大预览可以让单张卡片承载更多作品图，而不用继续往下展开详情区

## 5. 影响范围

- 影响页面：`/xiaohongshu` 的原创笔记分区
- 不影响原创笔记生成、保存、删除接口

## 6. 验证方式

- 构建验证：`apps/web` 执行 `npm run build` 通过
- 手工验证：检查原创笔记页头文案、卡片轮播按钮、图片放大预览和编辑弹窗

## 7. 风险与后续

- 当前图片放大预览为单张查看，若后续需要灯箱内继续左右切图，可再扩展为完整图片组模式
- 若后续要在卡片上显示更多元信息，可优先通过轻量标签而不是恢复下方详情区
