# 2026-05-18 视频提示词文件纳入仓库并改为仓库内优先加载

## 背景

视频笔记相关提示词在本地开发环境能够读取到完整内容，但推送部署后，前后台技能中心仍显示一行简版占位文案。根因并不是提示词注册关系错误，而是这批视频提示词文件原先位于仓库外层目录，部署环境并不会携带这些外部文件。

## 根因

- 原始文件位于仓库外层：
  - `AI全域智能体/提示词/视频生成提示词/*.txt`
- GitHub Actions 与服务器部署只会同步仓库 `ai-omni-ops-system` 内的内容
- 因此线上环境缺少这批源文件，运行时只能回退到数据库里旧的简版内容或占位文案

## 本次修正

### 1. 将视频提示词文件正式纳入仓库

新增目录：

- `提示词/视频生成提示词/品牌宣传剧本提示词.txt`
- `提示词/视频生成提示词/口播带货剧本提示词.txt`
- `提示词/视频生成提示词/短剧带货剧本提示词.txt`
- `提示词/视频生成提示词/拆解短视频提示词.txt`
- `提示词/视频生成提示词/生成故事板提示词.txt`
- `提示词/视频生成提示词/短视频提示词.txt`

### 2. 调整提示词源文件加载优先级

文件：

- `apps/server/src/common/prompt-source-loader.ts`

对视频笔记 6 条 prompt 的候选路径增加仓库内路径，并放在最前面：

- `提示词/视频生成提示词/*.txt`

这样无论是本地开发、构建后运行，还是 GitHub Actions 部署后的服务器环境，都会优先读取仓库内受 Git 管理的文件。

## 影响范围

- 后台技能中心 `/admin`
- 个人技能中心 `/personal-center/skills`
- 视频笔记 6 条提示词的显示、编辑基线与运行时读取
