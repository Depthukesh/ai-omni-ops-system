# 2026-05-21 抖音结果表格紧凑化与图片预览

## 背景

- 抖音采集结果表格目前以纯文本和链接为主，头像列无法直接预览。
- 简介、作品描述等长文本字段会直接撑高整行，不利于高密度浏览。
- 用户希望表格排版更接近飞书多维表格：紧凑、有序、点击单元格即可展开查看全文，并且表格超宽时应在表格区域内横向滚动，而不是把整页撑出边界。

## 本次调整

- 抖音账号表与作品表的头像/封面类字段改为直接显示缩略图预览，点击可打开原图。
- 简介、作品描述等长文本字段改为默认紧凑显示：
  - 单元格默认收起
  - 点击单元格本身即可展开
  - 展开后单元格内部支持纵向滚动
- 抖音表格不再通过容器拖拽改变页面宽度，而是固定在页面边界内展示。
- 当表格列过多超出可视宽度时，在表格顶部和表格内容区内部提供横向滚动能力。
- 同步压缩了抖音表格单元格 padding 与字号，增强信息密度。
- 长文本单元格在展开后提供独立的“复制 / 收起”按钮，文本内容可直接选中复制，不会因点击文本本身再次折叠。
