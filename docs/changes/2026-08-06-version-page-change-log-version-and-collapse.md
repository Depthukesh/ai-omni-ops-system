# 2026-08-06 版本页补版本号并折叠更新日志

## 为什么改

- 当前“版本与升级”页顶部主版本号一直显示 `0.1.0`，用户容易误以为页面没有刷新。
- 系统更新日志虽然已经持续累计，但每条只显示时间和内容，没有显式带出版本号。
- 当日志记录变多后，页面会被长列表撑得很长，阅读体验较差。

## 本次范围

- `apps/web/src/app/(dashboard)/personal-center/version/page.tsx`

## 这次改了什么

### 1. 更新日志显式显示版本号

- 每条系统更新日志现在都会显示 `appVersion`
- 如果当前记录没有版本号，会显示“版本号未记录”
- 打包名 `releaseTag` 继续保留在版本号下面，便于区分具体热修包

### 2. 更新日志改为可折叠

- 每条日志改为 `details / summary` 折叠结构
- 默认展开最新一条
- 历史日志默认折叠，避免页面继续无限拉长

## 版本号为什么一直是 0.1.0

- 当前页面主版本号来自根 `package.json` 的 `version`
- 目前仓库里的产品版本仍是：

```json
"version": "0.1.0"
```

- 近期连续发的 `hotfix-11` 到 `hotfix-17`，变化的是 `releaseTag`，不是根产品版本号
- 所以页面顶部主版本号会保持 `0.1.0`，而第二行打包名会变化

## 影响范围与边界

- 这次只调整版本页展示
- 不改升级协议、不改 OSS `latest.json` 结构、不改实际版本计算逻辑

## 验证

- 静态检查版本页渲染逻辑
- 确认更新日志列表已改为：
  - 时间
  - 版本号
  - 打包名
  - 折叠后的更新内容
