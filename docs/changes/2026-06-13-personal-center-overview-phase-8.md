# 2026-06-13 个人中心第八批开发：概览页动作入口化收口

## 为什么改

- 前几批已经把任务、订单、安全、技能、第三方平台和 OpenClaw 页面逐步收口。
- `personal-center/page.tsx` 概览页虽然信息完整，但仍偏“摘要堆叠”，还不够像运营用户每天进入系统后的动作入口。
- 本批继续只处理表达层和入口层，不修改业务逻辑、不增加接口负担。

## 本次范围

- `apps/web/src/app/(dashboard)/personal-center/page.tsx`
- `apps/web/src/styles/globals.css`

## 本次改动

### 1. 概览页顶部动作引导

- 在“个人中心概览”头部下方新增说明条，明确“先看任务、再看订单、账号资料去安全设置”。
- 让首页更像工作台入口，而不是继续展开长列表。

### 2. 新增三张主动作卡片

- 新增三张概览动作卡：
  - 查看进行中任务 / 去作品中心
  - 核对订单与充值
  - 维护账号资料
- 每张卡都改成“动作标签 + 当前摘要 + 下一步说明”的结构。

### 3. 当前待办补齐订单核对入口

- 在“当前待办”里加入订单与充值核对项。
- 让“邀请 / 任务 / 作品 / 订单 / 安全”这几类高频操作在概览页形成更完整的闭环。

### 4. 快捷入口文案收口

- 将快捷入口的描述统一改成更面向动作的语气，例如“去核对支付状态”“去处理成员协作”“去维护平台连接”。
- 避免概览页仍像说明书式文案。

### 5. 账号与品牌卡片补快捷动作

- 在“账号与品牌”卡片里追加“查看团队协作”入口。
- 把账号资料维护和团队关系处理放到更接近用户资料的位置。

### 6. 样式层补充

- 新增概览动作卡相关样式：
  - `personal-overview-action-grid`
  - `personal-overview-action-card`
  - `personal-overview-action-label`
- 并补上移动端单列收口，保证小屏下仍然清晰。

## 明确不改的内容

- 不修改登录流程、品牌切换逻辑和数据结构。
- 不新增接口请求。
- 不引入新依赖。
