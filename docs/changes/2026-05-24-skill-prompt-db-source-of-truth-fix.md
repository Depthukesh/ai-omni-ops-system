# 2026-05-24 技能提示词隔天回滚修复

## 背景
- 后台修改技能提示词后，当天页面和前台技能使用都能立即生效。
- 隔一段时间，尤其是服务重启或重新发布后，提示词会恢复成修改前的旧内容。

## 根因
- `PromptTemplate` 在后台编辑时会同时写数据库和本地提示词文件。
- 但服务初始化和读取链路又存在“文件为准”的反向同步逻辑：
  - 读取 `PromptTemplate` 时会用本地文件内容覆盖数据库内容。
  - 首次访问相关接口触发懒初始化时，也会把文件内容回填到已存在的数据库记录。
- 如果线上机器的本地文件在次日重启、发布或容器重建后回到仓库旧版本，就会把数据库里后台刚改过的内容刷回旧值。

## 修复
- 将平台级提示词的真源调整为：
  - 首次建库插入默认 prompt 时，允许从文件导入默认内容。
  - 后台编辑后，以数据库 `PromptTemplate.content` 为准。
  - 读取、列表展示、按场景获取时，不再用本地文件反向覆盖数据库。
- 仍保留后台保存时回写本地文件的能力，兼容本地开发和文件侧维护场景，但文件不再在后续重启时覆盖数据库。

## 影响
- 后台 `/admin` 修改的平台技能提示词会稳定持久化。
- 前台技能中心和实际运行链路下次读取会继续使用数据库中最新内容。
- 不再出现“后台刚改过，隔天又恢复旧值”的情况。
