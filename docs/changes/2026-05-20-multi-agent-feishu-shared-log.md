# 2026-05-20 多 Agent 飞书共享协作记录补充

## 背景

- 当前仓库已经引入第二个 AI Agent 的协作规则，但还缺少一份双方都持续写入的共享协作文档。
- 仅依赖仓库内文档和 Git 提交，无法满足任务开始前登记计划、任务结束后补写进度的近实时协作诉求。

## 本次补充

- 将指定飞书 Wiki 文档补充为主 Agent 与并行 Agent 的共享协作记录面。
- 明确补充新的固定协作入口与职责分工：
  - 用户后续默认只向主 Agent 下达指令
  - 主 Agent 负责统筹、网站框架和模块结构持续优化、网页页面制作、验证与 Git 收口
  - 并行 Agent 主要负责各模块内容的持续优化
- 明确要求双方在每次开始前写入：
  - 本轮任务标题
  - 各自计划
  - 预计影响范围
  - 是否涉及共享文件或潜在冲突文件
- 明确要求双方在每次结束后补写：
  - 实际完成进度
  - 已验证内容
  - 未完成事项
  - 下一步建议
- 同时补充规则：即使用户已经同步了 `docs/` 文档，并行 Agent 仍需自行从 GitHub 拉取最新代码，再开始执行。

## 影响范围

- `AGENTS.md`

## 结果说明

- 这次补充解决的是“多 Agent 如何共享计划与进度记录”的协作面问题。
- 仓库文档继续承担规则基线，飞书协作文档承担实时计划和进度同步，两者配合使用。
- 同时进一步固定了“主 Agent 负责统筹与结构、并行 Agent 负责内容优化”的长期分工。
