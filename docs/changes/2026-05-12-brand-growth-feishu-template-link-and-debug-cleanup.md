# 2026-05-12 品牌增长飞书模板链接与同步诊断清理

## 背景

品牌增长页的小红书收集区仍指向旧的飞书模板链接，且作品卡片保留了排障阶段临时加入的“同步诊断”面板，影响日常使用体验。

## 本次改动

- 将品牌增长页“打开飞书模板”的默认链接更新为新的飞书 Base 链接
- 删除品牌作品与对标作品卡片中的“同步诊断”折叠面板

## 影响范围

- `apps/web/src/app/(dashboard)/brand-growth/workspace.tsx`
- `apps/web/src/app/(dashboard)/brand-growth/collection-workspace.tsx`

## 验证

- 执行 `npm run build:web`
- 确认品牌增长页“小红书平台”中的“打开飞书模板”跳转到新的 Base 链接
- 确认作品卡片底部不再展示“同步诊断”

## 后续说明

- 若后续还需要排查飞书同步原始字段，优先通过开发态日志或临时调试开关处理，不再默认暴露到用户界面
