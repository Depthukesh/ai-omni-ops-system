# 2026-05-14 飞书部分表名命中后的缺项补齐

## 背景

- 品牌增长页执行“从飞书同步”时，页面提示“飞书同步完成，已更新 N 条结果，命中 4 张数据表”，但“对标作品信息及数据”区域仍显示 `已同步 0 条`。
- 根因不是飞书表字段被隐藏，也不是同步后的前端渲染问题，而是后端表匹配逻辑先按表名命中一部分表后会直接返回，导致剩余未命中的那张表不再继续走内容分类补齐。

## 本次调整

- `apps/server/src/modules/collectors/collectors.service.ts`
  - 调整 `matchFeishuTables()`：
    - 当 5 类表都已按名称命中时，维持原行为直接返回
    - 当只命中部分表时，继续执行 `classifyFeishuTablesByContent()`
    - 最终结果改为“名称命中优先，缺项再用内容分类补齐”

## 影响

- 飞书副本里即使只有 4 张表能按名称直接匹配，第 5 张也会继续按内容特征识别，而不会被旧的“部分命中即返回”逻辑跳过。
- 对标作品表名存在轻微变体、不可见字符或未被当前关键字完全覆盖时，仍有机会通过内容分类进入 `benchmarkNotes` 同步链路。
- 已稳定按表名命中的品牌账号、竞品账号、品牌作品、目标用户表不受影响。

## 验证

- `GetDiagnostics` 检查 `collectors.service.ts` 无报错
- `npm run build:server`

## 后续说明

- 本次修复只解决“部分表名命中后不再补齐缺项”的问题。
- 若后续仍出现对标作品行级数据为空，再继续排查具体字段别名或飞书行内容本身。
