# 2026-06-08 小红书/抖音桌面发布现状与视频号可行性评估

## 背景

- 本轮先后补齐了小红书图文电脑端草稿发布链路、抖音视频电脑端辅助发布链路，并尝试将两个平台收口为统一浏览器插件。
- 统一插件第一版在真实环境中出现了平台脚本互相干扰的问题：
  - 小红书原创图文被误导到视频上传页
  - 抖音发布页停在“正在获取完整发布素材”
- 经真实网页端运行日志取证后，已将平台入口重新拆回独立插件，并修复了抖音视频大文件在扩展消息通道中传输卡死的问题。
- 用户进一步要求本轮先更新文档，并确认两个判断：
  - 后续视频号是否也可以走同样的浏览器辅助发布模式
  - 当前是否适合再次统一为一个插件

## 当前结论

### 1. 当前真实可用的桌面发布能力

- 小红书：
  - 当前支持 `图文笔记 -> 电脑端扩展写入草稿箱`
  - 当前不支持视频笔记电脑端直发
- 抖音：
  - 当前支持 `视频作品 -> 电脑端扩展辅助发布`
  - 已支持自动上传视频、填写标题和描述，最后一步仍由人工点击发布
  - 当前未自动接管封面上传
  - 当前不支持抖音图文笔记电脑端发布

### 2. 为什么暂时不能继续统一为一个插件

- 小红书图文与抖音视频虽然都属于“浏览器辅助发布”，但页面模型和上传对象差异很大：
  - 小红书当前是图文草稿
  - 抖音当前是视频上传
- 第一版统一插件采用“简单拼接两个平台脚本”的方式，已在真实环境里验证会带来互相干扰。
- 因此当前结论是：
  - **技术上未来仍可做真正统一插件**
  - **当前阶段不建议重新合并**
  - 更合理的路线是：先把各平台独立链路调稳，再在更高一层做统一路由壳，而不是继续拼接脚本

### 3. 视频号是否可以同样走浏览器辅助发布

- 方向上 **可以**。
- 已核对视频号官方帮助中心说明：
  - 电脑端浏览器登录 `https://channels.weixin.qq.com`
  - 支持电脑端发表视频
  - 支持电脑端发表图文
- 这说明视频号具备真实存在的网页创作者入口，且不是只能依赖手机发布。

### 4. 视频号与当前抖音方案的差异

- 虽然方向可行，但视频号并不等于“直接复制抖音插件即可”。
- 当前已知风险包括：
  - 登录依赖微信扫码，登录态与浏览器环境更敏感
  - 图文和视频在同一平台内就分为两条不同入口
  - 页面控件、编辑器、素材上传区、封面区、权限提示和风控提示都需要重新适配
  - 若上传视频编码不兼容，网页端可能仍会受浏览器能力限制
- 因此对视频号更准确的判断是：
  - **可做浏览器辅助发布**
  - **不能假设与抖音难度相同**
  - **应按独立平台新建插件链路，而不是直接复用抖音脚本**

## 本轮实际代码状态

### 1. 小红书桌面发布

- 页面继续引导用户安装独立小红书扩展：
  - `apps/web/src/app/(dashboard)/xiaohongshu/publish-modal.tsx`
  - `apps/web/src/app/help/xhs-draft-publisher/page.tsx`
- 当前帮助文案已明确：
  - 仅支持图文笔记草稿箱

### 2. 抖音桌面发布

- 页面继续引导用户安装独立抖音扩展：
  - `apps/web/src/app/(dashboard)/douyin/publish-modal.tsx`
  - `apps/web/src/app/help/douyin-publisher/page.tsx`
- 当前帮助文案已明确：
  - 仅支持视频作品
- 抖音扩展经过网页端日志排障后，已将“大视频二进制下载”移动到 creator 页内部执行，避免通过 `chrome.runtime.sendMessage` 传输大文件导致卡死。

### 3. 浏览器调试采集

- 本轮为抖音网页端排障临时补了远程浏览器日志采集接口：
  - `POST /api/debug/browser-event`
  - `GET /api/debug/browser-logs`
  - `DELETE /api/debug/browser-logs`
- 该接口当前主要用于抖音桌面发布调试，后续如果视频号链路启动，也可沿用相同方式做网页端取证。

## 对后续开发的建议

### 第一优先级

- 先保持“小红书图文独立插件 + 抖音视频独立插件”的结构，不再重新合并。
- 等各自链路稳定后，再考虑做真正统一的插件路由壳。

### 第二优先级

- 抖音后续可继续补：
  - 封面自动上传
  - 发布状态更完整回显
  - 更多页面选择器稳定性收口

### 第三优先级

- 视频号建议按新平台独立立项，先做最小能力验证：
  - 能否打开 `channels.weixin.qq.com`
  - 能否稳定注入 content script
  - 能否完成视频上传
  - 能否完成图文发布页字段填写
- 验证完成前，不建议把视频号直接纳入“统一插件”规划。
