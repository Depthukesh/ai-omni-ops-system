# 2026-06-12 个人中心第四批上线：视觉一致性收口

## 为什么改

- 前三批已经完成个人中心主要页面的壳层统一、文案修复和概览页收口。
- 剩余问题主要集中在视觉一致性上，例如空态、工具栏、次级按钮、数据卡片和表格表头仍偏旧版风格。
- 本批继续遵守低风险原则，只处理 `personal-center` 范围，不改业务逻辑。

## 本次范围

- `apps/web/src/styles/globals.css`
- `apps/web/src/app/(dashboard)/personal-center/layout.tsx`
- `apps/web/src/app/(dashboard)/personal-center/skills/page.tsx`

## 这次改了什么

### 1. 个人中心壳层样式

- 为个人中心顶部工作区壳层新增独立样式作用域。
- 统一面板、导航筛选、状态条和顶部信息区的边框、阴影和圆角体系。
- 保持深色工作台背景下的明亮内容面板风格，但提升整体质感和一致性。

### 2. 二级页视觉收口

- 统一 `metric-card`、`light-data-panel`、`entity-card` 的圆角、边框和渐变背景。
- 优化 `workspace-status`、`status-text`、`empty-canvas-box` 的视觉层级。
- 调整表格表头、悬停反馈和输入框样式，让团队、邀请、技能、第三方平台等页更像同一套产品。

### 3. 移动端细节

- 为个人中心顶部壳层和二级页标题区补充小屏下的纵向排布。
- 缩小移动端空态区与数据卡片标题字号，减少拥挤感。

### 4. 零散文案修复

- 修复技能中心剩余的 `平台 Tokens`、`温度`、`最大 Tokens` 等标签乱码。

## 明确不改的内容

- 不改登录、鉴权、接口协议和数据库结构。
- 不新增接口请求，不增加服务器负担。
- 不引入重动画、复杂前端状态或额外依赖。
