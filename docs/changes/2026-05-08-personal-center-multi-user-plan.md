# 2026-05-08 个人中心多用户系统方案补充

## 1. 变更背景

- 用户要求围绕个人中心继续向多用户系统推进
- 并新增四项核心约束：
  - 前后端都要有任务管理模块
  - 每个用户要有自己的技能覆盖与重置能力
  - 每个品牌下可添加子用户并配置不同权限
  - 后台用户管理需要支持管理员权限和普通/会员用户等身份管理
