# 2026-08-27 品牌增长选题库结构化与 OpenClaw 共用改造

## 背景

原来的 `品牌增长报告 -> 选题库` 仍带着旧“热点找选题”沉淀页语义：

1. 页面里还保留了“热门找选题 / 热点找选题”板块。
2. 手动新增只支持 `选题内容 + 选题说明` 两个旧字段。
3. 无论是人工还是 OpenClaw，都缺少统一的单条查看、编辑、删除能力。
4. 选题库字段仍偏抖音，不适合视频号、小红书、公众号等平台共用。

## 本次改动

### 1. 品牌增长页收口为纯结构化选题库

- `品牌增长报告 -> 选题库` 页面去掉“热点找选题”区块。
- 页面顶部说明改为结构化、人机共创的选题沉淀口径。
- 当前品牌增长页只保留：
  - 刷新
  - 添加选题
  - 查看
  - 编辑
  - 删除

### 2. 选题库条目升级为结构化字段

选题库条目当前统一支持以下字段：

- `选题标题`
- `选题内容`
- `选题平台`
  - 抖音
  - 视频号
  - 小红书
  - 公众号
- `内容形式`
  - 图文
  - 视频
  - 长文章
- `呈现形式`
- `选题目的`
- `调用专家/技能`
- `是否可复用`
- `复用周期`

同时继续兼容旧链路仍会消费的字段：

- `topicContent`
- `topicDescription`

### 3. 人工与 OpenClaw 共用同一份选题库

- 网页人工创建的选题，直接写入品牌级选题库资产。
- OpenClaw 新增单条 CRUD：
  - `create_brand_growth_topic_library_item`
  - `update_brand_growth_topic_library_item`
  - `delete_brand_growth_topic_library_item`
- 原有整份更新入口仍保留：
  - `update_brand_growth_topic_library`

### 4. 抖音工作台保持兼容

- 抖音工作台仍保留“热点找选题”能力。
- 从热点加入选题库时，会自动补齐结构化字段默认值：
  - 平台默认 `抖音`
  - 内容形式默认 `视频`
  - 来源标记为 `GENERATED`
- 原创文案选题下拉改为优先显示 `topicTitle`，并继续兼容旧 `topicContent`。

### 5. 持久化与老数据兼容

- 本轮未改数据库 schema。
- 继续沿用品牌级 `BusinessAsset.metadataJson.kind = DOUYIN_TOPIC_LIBRARY` 作为真源。
- 旧数据在读取时会自动归一化补齐默认字段，避免历史品牌选题直接失效。

## 影响范围检查

- 影响板块：
  - `品牌增长 -> 品牌增长报告 -> 选题库`
  - `抖音 -> 选题库`
  - `抖音 -> 原创文案` 的选题展示文案
  - OpenClaw / MCP / Skill 的品牌增长选题库工具
- 未改动：
  - 数据库 schema
  - 抖音热点找选题生成接口本身
  - 原创文案主流程协议
- 额外保护：
  - 选题库读取继续兼容旧字段
  - 原创文案继续可读 `topicContent / topicDescription`
  - OpenClaw 单条 CRUD 最终仍落到同一份品牌选题库资产，避免出现第二份真源
