# 2026-06-07 技能中心模块与能力包筛选第一批接线

## 背景

- 前一轮已经完成：
  - 技能中心显示所属模块
  - 技能中心显示所属能力包
  - 技能中心显示归属说明
- 但这些关系还只是“可见”，还没有真正作用于后台检索和管理。
- 为了让模块化关系能参与后台运营，本轮继续把“模块 / 能力包”接入技能目录筛选。

## 本次改动

### 1. 技能树支持按模块筛选

- 修改：
  - `apps/web/src/app/(dashboard)/admin/page.tsx`
- 新增：
  - `模块筛选`
- 作用：
  - 只显示属于指定模块的技能项
  - 让后台可以快速收口查看某个工作台真正挂载了哪些技能

### 2. 技能树支持按能力包筛选

- 修改：
  - `apps/web/src/app/(dashboard)/admin/page.tsx`
- 新增：
  - `能力包筛选`
- 作用：
  - 只显示挂在某个能力包下的技能项
  - 为后续“能力包版本管理”和“影响范围反查”做前台入口

### 3. 技能树支持关键词筛选

- 修改：
  - `apps/web/src/app/(dashboard)/admin/page.tsx`
- 新增：
  - `关键词`
- 当前支持匹配：
  - 模块标识
  - 能力包标识
  - 能力包名称
  - 技能标识
  - 提示词场景
  - 技能项标题和描述

### 4. 筛选结果直接作用于左侧技能目录树

- 本轮不是只在右侧详情面板做过滤。
- 当前实现会直接裁剪左侧技能目录树：
  - 一级分类
  - 二级分类
  - 三级技能项
- 当筛选条件变化时：
  - 如果当前选中的技能项已经不在结果中，会自动切到筛选结果中的第一项
  - 如果没有结果，则展示空态提示

## 当前效果

- 后台技能中心已经支持：
  - 按模块看技能
  - 按能力包看技能
  - 按关键词搜技能
- 这使技能中心从“静态配置页”开始转成“可按模块化关系检索的管理页”。

## 架构意义

- 模块、能力包、技能三者之间的关系，开始真正用于后台运营。
- 后续继续推进时，可以直接在这套筛选基础上补：
  - 按模块批量检查技能状态
  - 按能力包检查提示词、模型、版本
  - 后台创建技能后自动挂入模块和能力包
