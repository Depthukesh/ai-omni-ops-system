# 2026-05-09 个人中心订单中心第一版

## 1. 变更背景

- 个人中心已经拆出 `/tasks`、`/team`、`/invites`，但订单仍停留在概览页聚合展示，无法形成真正可持续扩展的二级路由结构
- 当前后端 `OrdersModule` 已具备按当前登录用户过滤订单的基础能力，适合先补一个最小可用的订单中心

## 2. 本次目标

- 新增 `/personal-center/orders`
- 让用户可以在个人中心独立查看会员订单与点数充值记录
- 提供状态筛选、类型筛选、关键词搜索、摘要卡片和订单详情跳转
- 不扩 schema，不额外拉大订单后端改动范围

## 3. 本次修改

### 3.1 前端路由壳

- 更新 `apps/web/src/app/(dashboard)/personal-center/layout.tsx`
- 个人中心二级导航新增：
  - `订单中心`
- 路由壳说明同步补充当前已拆出的任务、订单、团队、邀请四类工作区

### 3.2 共享辅助

- 更新 `apps/web/src/app/(dashboard)/personal-center/route-helpers.ts`
- 新增：
  - `personalOrderStatusClassMap`
- 用于统一订单状态徽标样式，避免在订单页重复硬编码

### 3.3 订单中心页面

- 新增 `apps/web/src/app/(dashboard)/personal-center/orders/page.tsx`
- 当前能力：
  - 校验登录态
  - 读取真实 `/auth/me`
  - 读取真实 `/orders`
  - 支持品牌上下文切换与退出登录
  - 支持订单状态筛选、订单类型筛选、关键词搜索
  - 支持查看：
    - 订单总数
    - 已支付数
    - 待支付数
    - 会员订单数
    - 点数充值数
    - 当前筛选金额汇总
  - 支持跳转 `/orders/[id]` 查看订单详情
  - 订单接口失败时回退 `orderSeed`

## 4. 验证结果

- `GetDiagnostics` 检查待执行
- 页面级验证待执行：
  - `/personal-center/orders` 可访问
  - 状态筛选、类型筛选、关键词搜索可用
  - 订单详情跳转可用

## 5. 当前边界

- 当前订单中心仍主要按“当前登录用户”维度过滤，品牌级订单归属和品牌内订单共享能力后续再补
- 本次未扩展订单 schema，也未新增订单摘要专用接口
- 订单中心当前聚焦会员订单和点数充值两类记录，发票、退款、后台审核和财务对账暂未纳入
