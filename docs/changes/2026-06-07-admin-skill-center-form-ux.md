# 2026-06-07 Admin Skill Center Form UX

## 背景

- 后台技能中心中，“能力包摘要视图”和“创建技能”原先混在同一工作区里，阅读和填写干扰较大。
- 创建技能、References、知识库文件等场景仍有较多自由输入框，容易出现“不会填”或“填错”的问题。

## 本次改动

- 技能中心新增左侧工作台菜单：
  - `能力包摘要`
  - `创建技能`
- `创建技能` 从弹窗调整为页面内独立工作台。
- `创建技能` 中以下字段改为下拉优先：
  - 分类
  - 状态
  - 供应商
  - 默认模型
  - 所属模块
  - 所属能力包
  - 提示词场景
- 知识库文件新增本地文件选择入口：
  - 选择文件后自动带入文件名、文件类型、来源
- 能力包详情 `References` 资产新增本地文件选择入口：
  - 选择文件后自动带入标识、标题、来源类型、来源地址
- 能力包详情 `Prompt` 资产中的模型改为按可用 Provider 生成的下拉
- 能力包详情 `Provider` 绑定中的模型改为按所选 Provider 联动生成的下拉

## 当前边界

- 本次上传仍属于“前端选择文件并自动带入元数据”的 first pass。
- 当前还没有把 `References` 或知识库文件做成真实二进制上传到后端存储。

## 验证

- `npm --workspace apps/web exec tsc --noEmit`
