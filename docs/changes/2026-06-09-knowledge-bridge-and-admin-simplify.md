# 2026-06-09 企业经营数据入知识库与后台简化

## 本次变更

- 前端 `品牌资料库 -> 企业经营数据` 页面补充了“保存后自动同步到知识库”的明确提示。
- 企业经营数据上传区改为更接近知识库上传的卡片式样，保留本地文档上传，同时增加知识库桥接说明。
- 品牌端保存企业经营数据后，会自动桥接到对应品牌的经营数据知识库：
  - 自动创建或更新知识库
  - 自动生成知识库文件记录
  - 自动绑定到 `brand-growth-workbench`
- 后台知识库管理页从“整页平铺所有治理项”改成：
  - 左侧：新建知识库、知识库列表、板块菜单
  - 右侧：当前知识库的当前板块内容
- 后台隐藏了不需要频繁手工干预的内容：
  - 不再直接暴露同步状态手工编辑
  - 不再直接暴露文件状态手工切换
  - 不再在同步记录里提供手工标记成功/失败

## 当前可测试路径

1. 在前端品牌增长工作台进入“品牌资料库 -> 企业经营数据”
2. 上传文档并保存页面
3. 进入后台 `知识库管理`
4. 可看到系统自动生成的品牌经营数据知识库，以及对应资料记录
5. 在后台知识库页触发同步

## 仍未完成

- 当前知识库同步仍是最小 ingestion 骨架，还未接真实文档正文解析与向量索引。
- 企业经营数据虽然已进入知识库治理层，但运行时报告链路仍未改为从知识检索结果取数。
