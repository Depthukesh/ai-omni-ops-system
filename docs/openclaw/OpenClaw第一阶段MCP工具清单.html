OpenClaw 第一阶段 MCP 工具清单

这份文档只定义我们系统侧第一阶段需要提供给 OpenClaw 的 MCP 工具，不讨论 OpenClaw 自身模型、安装或渠道部署细节。目标是把网站现有能力和历史数据整理成一组可安全调用、标准化、可直接服务于 12 个高频任务的工具清单。

边界只做我们系统侧 MCP，不碰 OpenClaw 自身配置。
原则先服务高频任务，不先暴露全部系统接口。
安全所有工具都带身份和品牌上下文，不直连数据库。
输出优先摘要、关键字段和深链接，不优先原始明细。

工具分组

品牌上下文

识别用户、默认品牌、角色和权限范围。

任务与报告

查询任务摘要、总结失败原因、触发报告和规划。

知识库

查看知识库、新增资料、新建知识库、上传资料。

技能配置

查看品牌覆盖和技能配置摘要。

内容生成

触发小红书原创图文和公众号文章，并回读摘要。

历史分析

做高表现内容规律总结和时间段对比。

任务映射

查询类任务

  • 看最近任务情况 → `get_recent_tasks_summary`
  • 总结失败任务原因 → `summarize_failed_tasks`
  • 查看知识库和最近新增资料 → `list_knowledge_bases` + `list_recent_knowledge_files`
  • 看当前技能配置摘要 → `get_skill_config_summary`

触发与分析类任务

  • 品牌增长报告 → `create_brand_growth_report` + `get_task_result_summary`
  • 半年营销规划 → `create_half_year_marketing_plan`
  • 小红书原创图文 → `create_xiaohongshu_original_note`
  • 公众号文章 → `create_wechat_article`
  • 高表现内容规律 → `summarize_top_content_patterns`
  • 时间对比 → `compare_period_metrics`

不建议优先暴露

第一阶段不建议优先暴露批量删除、高风险导出、大规模原始明细查询、跨品牌复杂写入、直接修改核心技能基线等工具。MCP 第一阶段应服务顺滑高频任务，而不是搬运整套后台接口。
