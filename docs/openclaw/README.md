## 本方案适用范围

- 当前系统为“单库多品牌”架构。
- 后台平台基线技能中心为全局共享。
- 前端用户中心技能中心为品牌级共享覆盖。
- OpenClaw 目标定位为“品牌运营智能助手”，不是数据库直连机器人。

## 核心原则

1. OpenClaw 不直接连接数据库。
2. OpenClaw 通过受控 API / Tool / MCP 层读取品牌数据和触发功能。
3. OpenClaw 所有请求必须带用户身份和品牌上下文。
4. OpenClaw 只可访问用户在当前品牌权限范围内可读写的数据。
5. 高风险写操作必须可审计、可确认、可回滚。
