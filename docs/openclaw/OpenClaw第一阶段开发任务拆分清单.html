可直接排期的开工清单

OpenClaw 第一阶段开发任务拆分清单

这份文档把高频用户任务进一步拆到开发层，直接回答每个任务要接哪些后端能力、要调哪些历史数据、 最小渠道侧交互和网站侧配合是什么，以及应该排在什么优先级。目标不是讲方案，而是帮助研发按“任务”而不是按“模块”开工。

拆分方式 按用户任务拆，不按系统模块拆。
第一目标 优先打通最小闭环：能识别、能带品牌、能调历史数据、能出摘要。
底座策略 第一阶段优先复用现有认证、任务中心、知识库、技能中心和生成链路。
排期策略 P0 先做到问了就能看，P1 再做到说了就能做，P2 再做到帮我总结和判断。

任务分组

P0：问了就能看

  • 看最近任务情况
  • 总结失败任务原因
  • 查看知识库和最近新增资料
  • 看当前技能配置摘要
  • 生成品牌增长报告

P1：说了就能做

  • 生成半年营销规划
  • 做一版小红书原创图文
  • 生成公众号文章
  • 新建知识库
  • 上传知识资料

P2：能帮我总结和判断

  • 总结最近表现最好的内容规律
  • 对比这个月和上个月的变化

核心任务映射

任务 后端能力 历史数据 最小渠道侧交互 / 网站侧配合 优先级
看最近任务情况 品牌上下文、任务列表、状态聚合、类型聚合 近 7/30 天任务历史、阶段、类型 渠道内返回摘要；支持展开失败任务；必要时深链接到任务中心 P0
总结失败任务原因 失败任务筛选、错误聚合、原因分类 失败历史、错误摘要、重试记录、知识调用摘要 渠道内返回失败原因 Top3；必要时展开明细 P0
生成品牌增长报告 报告任务触发、Task 状态读取、报告摘要回读 历史品牌增长报告、知识绑定运行时 渠道内回传任务受理、进度和摘要；需要时深链接到完整报告 P0
查看知识库和最近新增资料 知识库列表、资料列表、同步状态读取 知识库历史、上传记录、同步记录 渠道内返回知识库摘要和最近资料；需要时深链接到知识库页 P0
看当前技能配置摘要 能力包列表、技能详情、品牌覆盖读取 品牌覆盖历史、最近配置变更 渠道内返回配置摘要；需要时深链接到完整配置页 P0
生成半年营销规划 规划任务触发、Task 回读、规划摘要 品牌档案、历史报告、产品资料、知识库资料 渠道内回传任务反馈和规划摘要；支持继续细化 P1
做一版小红书原创图文 原创图文任务触发、任务状态回读、结果摘要 品牌资料、产品信息、历史小红书内容、高表现规律 渠道内回传任务反馈和摘要；支持再来一版和打开完整结果 P1
生成公众号文章 文章任务触发、文章结果读取、任务状态回读 品牌资料、历史公众号文章、知识库资料 渠道内回传任务反馈和文章摘要；支持继续改写和打开全文 P1
新建知识库 知识库创建接口 当前品牌上下文 渠道内缺名称时追问 1 次；创建成功后引导继续上传资料 P1
上传知识资料 文件上传、资料入库、切片/同步任务触发 目标知识库、上传历史、同步任务状态 渠道内选择目标知识库并轻确认；回传上传进度和完成摘要 P1
总结最近表现最好的内容规律 历史内容读取、表现数据聚合、规律摘要生成 内容历史、表现指标、时间范围、平台类型 渠道内返回规律摘要和 Top 内容；支持继续生成类似内容 P2
对比这个月和上个月的变化 时间对比聚合、任务/内容/报告多源聚合 任务历史、内容历史、报告历史、时间段对比结果 渠道内返回变化摘要和上升/下降项；支持展开原因 P2

公共开发项

后端公共项

  • Assistant 授权与会话
  • 当前品牌上下文继承
  • MCP 工具执行层
  • 历史数据聚合层
  • Data View 裁剪层
  • 审计日志

渠道侧公共项

  • 飞书 / 企微等渠道接入与会话路由
  • 首次绑定消息与账号关联流程
  • 渠道内结构化消息模板
  • 文件 / 图片 / 链接回传能力
  • 错误提示与重试消息
  • 深链接到网站结果页或管理页

网站侧最小配合项

  • 账号绑定或授权回调页
  • 受控 API / MCP 能力层
  • 复杂结果查看页
  • 配置与审计管理页
  • 深链接落点页

体验公共项

体验约束

  • 默认使用当前品牌
  • 默认时间范围策略
  • 单次最多 1 到 2 次追问
  • 高风险动作确认
  • 结果先摘要

  • 看最近任务情况
  • 查看知识库和最近新增资料
  • 看当前技能配置摘要

Sprint 2

  • 总结失败任务原因
  • 生成品牌增长报告
  • 新建知识库
  • 上传知识资料

Sprint 3

  • 生成半年营销规划
  • 做一版小红书原创图文
  • 生成公众号文章

Sprint 4

  • 总结高表现内容规律
  • 对比这个月和上个月的变化
  • 优化默认参数与追问策略

最终目标

第一阶段最重要的不是把所有能力都接上，而是先围绕 12 个高频任务打通最小闭环： 能识别、能自动带入品牌、能调历史数据、能输出摘要、能顺滑完成。只要这 12 个任务做顺， 用户就会明确感受到它不是一个聊天壳子，而是真正能帮忙完成工作的助手。
