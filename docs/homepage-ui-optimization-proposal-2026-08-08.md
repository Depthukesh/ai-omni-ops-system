# 系统内页简洁版方案（finesse-brief）

## 目标

把进入系统后的第一页从“信息很多的目录页”，改成“看一眼就知道下一步该做什么的工作台首页”。

这次只做一件事：

- 让 `/brand-growth` 更简洁、更干净、更像真正的系统入口

## 方案结论

页面只保留 4 个层级：

1. 顶部：品牌名 + 一个主按钮
2. 首屏：一句主标题 + 3 个关键状态
3. 主区：3 个核心入口
4. 侧区：今日重点 + 最近更新

## 要删掉的内容

这次应该主动删掉这些内容：

- 大段解释文字
- 过多统计卡
- 过多标签和状态 pill
- 复杂的工作区说明
- 一屏里出现太多“下一步建议”
- 不影响当前决策的信息

原则是：

- 不能帮助用户马上行动的信息，就先去掉

## 要保留的内容

只保留最重要的 5 类信息：

1. 当前在哪个品牌空间
2. 今天最重要的动作
3. 当前系统处在哪个阶段
4. 3 个最高频入口
5. 最近一次有效输出

## 页面结构

### 1. 顶部导航

做轻，不要重。

只保留：

- Logo / 品牌名
- 页面名
- 搜索
- 一个主按钮

### 2. 首屏 Hero

首屏不要讲太多。

只表达：

- 当前品牌增长工作台
- 今天优先处理什么
- 现在可以从哪里继续

文案要短，最好一眼读完。

### 3. 三个核心入口

只保留三个卡片：

- 数据采集
- 增长报告
- 内容执行

它们代表完整主链，已经够用了。

不要再把所有能力一口气铺开。

### 4. 右侧信息区

右侧只保留两个盒子：

- 今日重点
- 最近更新

这样用户进入页面后不会被大量次级信息打断。

## 视觉方向

这版不再走“深色炫技中台”。

改成：

- 浅色背景
- 白卡片
- 细边框
- 少颜色
- 大留白
- 短文案

关键词：

- 简洁
- 干净
- 克制
- 产品感

## 这次 HTML 预览要验证什么

只验证 3 件事：

1. 页面是不是明显更清爽
2. 文字是不是明显更少
3. 用户是不是更快知道下一步操作

## 下一步正式落地建议

如果这版方向对，就直接把它收敛成 `/brand-growth` 的总览层。

先改入口层，不动下面各业务页。
