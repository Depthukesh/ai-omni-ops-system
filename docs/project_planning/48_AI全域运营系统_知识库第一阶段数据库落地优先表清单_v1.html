AI全域运营系统 知识库第一阶段数据库落地优先表清单 v1

本清单用于把知识库方向的对象、关系和接口收束成可执行的建表顺序。

最小可运行数据集： 先把 knowledge_spaces、knowledge_documents、knowledge_bindings 跑起来，就能支撑知识库后台管理和绑定关系。

1. P0 优先表

  • knowledge_spaces
  • knowledge_documents
  • knowledge_bindings

2. P1 / P2 优先表

P1： knowledge_tags、knowledge_space_tags、knowledge_retrieval_configs、skill_package_knowledge_spaces

P2： knowledge_chunks、knowledge_embeddings、knowledge_retrieval_logs、knowledge_source_sync_tasks

3. 建表批次建议

  • 批次 A： knowledge_spaces、knowledge_documents
  • 批次 B： knowledge_bindings
  • 批次 C： knowledge_tags、knowledge_space_tags、knowledge_retrieval_configs
  • 批次 D： skill_package_knowledge_spaces
  • 批次 E： 切片、向量、日志、同步任务相关表

4. 结论

知识库第一阶段不要一开始就把检索和向量能力全部做完，先让空间管理、文档管理和绑定关系稳定落地，会更稳，也更符合不影响现有网站运行的原则。
