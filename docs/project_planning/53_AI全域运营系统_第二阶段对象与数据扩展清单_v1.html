AI全域运营系统 第二阶段对象与数据扩展清单 v1

本文档定义第二阶段启动批次的新增对象、复用对象与字段含义，作为数据库和接口扩展的统一依据。

1. 新增对象

核心新增：SkillPackageKnowledgeSpace。
  • 字段：packageId、packageKey、packageName、knowledgeBaseId
  • 治理字段：relationType、priority、retrievalMode、isRequired、enabled、remarks
  • 唯一约束：packageKey + knowledgeBaseId + relationType

2. 复用对象

  • KnowledgeBase：继续作为知识空间主档
  • SkillPackage：继续作为能力包主对象
  • KnowledgeBinding：继续作为第一阶段通用桥接层

3. 字段语义

  • relationType：当前主用 DEFAULT 与 OPTIONAL
  • retrievalMode：SEMANTIC / HYBRID / MANUAL
  • priority：数字越小优先级越高，默认 100
  • isRequired：标记是否为必带知识空间

4. 数据策略

  • 数据库可用时优先读写 PostgreSQL
  • 数据库不可用时回退 mock-data.skillPackageKnowledgeSpaces
  • 保留少量种子关系用于后台演示与联调
