AI全域运营系统统一技能中心列表接口草案 v1

本草案用于把统一技能中心推进到列表接口层，指导列表页分页、搜索、筛选和摘要数据返回设计。

1. 主接口建议

GET /api/admin/skill-packages

该接口面向统一技能中心列表页、能力包选择弹窗和模块默认能力包选择器。

2. 核心查询参数

  • keyword、moduleKey、status、scope
  • page、pageSize、sortBy、sortOrder
P0： 先支持分页、关键词搜索、状态筛选、模块筛选、更新时间排序。

3. 返回结构草案

export interface SkillPackageListResponse {
  items: SkillPackageListItemDTO[];
  page: number;
  pageSize: number;
  total: number;
  totalPages: number;
}

列表项建议返回能力包名称、标识、所属模块、状态、当前版本、默认 Provider 摘要、覆盖数量和更新时间。

4. 列表页字段建议

  • packageName
  • packageKey
  • moduleSummaries
  • status
  • currentVersionNumber
  • defaultProviderSummary
  • brandOverrideCount
  • updatedAt

5. 结论

第一阶段列表接口的目标不是做复杂检索中心，而是先稳定支撑查找、筛选和进入详情页三件事。
