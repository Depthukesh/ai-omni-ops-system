# AI全域运营系统 模块注册中心列表页字段清单 v1

## 1. 文档目的

本文档用于把《ModuleDefinition 注册后台表单字段草案 v1》进一步下钻成模块注册中心列表页字段清单，用于：

- 指导模块注册中心列表页开发
- 指导后端列表接口返回字段设计
- 统一模块列表页的展示边界

## 2. 页面范围

本清单只覆盖“模块注册中心列表页”，不包含详情编辑表单页。

列表页建议分成三部分：

1. 顶部操作区
2. 筛选区
3. 表格列表区

## 3. 顶部操作区字段

| 字段名 | 展示名称 | 来源对象 | 展示方式 | 优先级 |
|---|---|---|---|---|
| `pageTitle` | 页面标题 | 固定文案 | 标题 | `P0` |
| `createAction` | 新建模块 | 固定动作 | 按钮 | `P0` |
| `searchKeyword` | 搜索框 | 查询参数 | 输入框 | `P0` |
| `refreshAction` | 刷新 | 固定动作 | 按钮 | `P1` |

## 4. 筛选区字段清单

| 字段名 | 展示名称 | 来源对象 | 说明 | 优先级 |
|---|---|---|---|---|
| `moduleType` | 模块类型 | `ModuleDefinition` | `WORKBENCH` / `DOMAIN` / `ADMIN_TOOL` | `P0` |
| `moduleStatus` | 模块状态 | `ModuleDefinition` | `PLANNING` / `ACTIVE` / `DISABLED` / `ARCHIVED` | `P0` |
| `phasePriority` | 阶段优先级 | 聚合字段 | `P0` / `P1` / `P2` | `P1` |
| `enabledOnly` | 仅看启用 | 聚合筛选 | 快速过滤启用状态 | `P1` |
| `hasDefaultSkillPackages` | 已绑定能力包 | 聚合筛选 | 是否已配置默认能力包 | `P1` |

## 5. 表格字段清单

| 字段名 | 展示名称 | 来源对象 | 说明 | 优先级 |
|---|---|---|---|---|
| `moduleName` | 模块名称 | `ModuleDefinition` | 主展示字段 | `P0` |
| `moduleKey` | 模块标识 | `ModuleDefinition` | 唯一标识 | `P0` |
| `moduleType` | 模块类型 | `ModuleDefinition` | 标签展示 | `P0` |
| `moduleStatus` | 模块状态 | `ModuleDefinition` | 状态标签 | `P0` |
| `entryRoute` | 入口路由 | `ModuleDefinition` | 路由展示 | `P0` |
| `defaultSkillPackageCount` | 默认能力包数 | 聚合字段 | 显示绑定数量 | `P0` |
| `taskTypeCount` | 任务类型数 | 聚合字段 | 显示任务类型数量 | `P1` |
| `requiredCapabilityCount` | 能力依赖数 | 聚合字段 | 显示依赖能力数 | `P1` |
| `phasePriority` | 阶段优先级 | 聚合字段 | 排期辅助信息 | `P1` |
| `updatedAt` | 最近更新时间 | 审计字段 | 时间文本 | `P0` |

## 6. 行操作字段

| 字段名 | 展示名称 | 说明 | 优先级 |
|---|---|---|---|
| `viewDetailAction` | 查看详情 | 打开模块编辑页 | `P0` |
| `copyAction` | 复制模块 | 复制已有模块定义 | `P1` |
| `enableAction` | 启用 | 将模块切换为启用 | `P1` |
| `disableAction` | 停用 | 将模块切换为停用 | `P1` |

## 7. 列表接口返回草案

```ts
export interface ModuleDefinitionListResponse {
  items: ModuleDefinitionListItemDTO[];
  page: number;
  pageSize: number;
  total: number;
  totalPages: number;
}

export interface ModuleDefinitionListItemDTO {
  moduleKey: string;
  moduleName: string;
  moduleType: string;
  moduleStatus: string;
  entryRoute: string;
  defaultSkillPackageCount: number;
  taskTypeCount: number;
  requiredCapabilityCount: number;
  phasePriority?: string;
  updatedAt?: string;
}
```

## 8. 第一阶段推荐展示集合

### P0

- `moduleName`
- `moduleKey`
- `moduleType`
- `moduleStatus`
- `entryRoute`
- `defaultSkillPackageCount`
- `updatedAt`

### P1

- `taskTypeCount`
- `requiredCapabilityCount`
- `phasePriority`
- 复制 / 启用 / 停用操作

## 9. 不建议第一阶段直接展示的内容

不建议在列表页直接展开：

- `requiredPermissions` 全量明细
- `requiredTables` 全量明细
- `taskTypes` 全量内容
- `defaultSkillPackages` 具体名称列表

这些内容更适合放到详情页或抽屉中。

## 10. 页面交互建议

第一阶段建议支持：

- 搜索模块名称和标识
- 按模块类型筛选
- 按状态筛选
- 跳转到详情页

第一阶段可延后：

- 多选批量操作
- 列配置自定义
- 导出 CSV

## 11. 最终结论

模块注册中心列表页第一阶段最关键的，不是展示所有字段，而是先让用户能够：

- 快速找到模块
- 快速判断模块状态
- 快速进入配置页

只要这三点跑通，模块注册中心就已经具备实用价值。
