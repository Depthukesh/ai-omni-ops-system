AI全域运营系统 第二阶段范围与边界说明 v1

本文档定义第二阶段启动批次的工作范围、排除项和工程边界，确保知识主线在不影响现有网站运行的前提下推进。

1. 总目标

本轮主题：知识库与能力包深度联动。

本轮重点把第一阶段桥接式知识能力推进为能力包与知识空间的独立关系层，并补齐后台治理入口。

2. 纳入范围

  • 新增 SkillPackageKnowledgeSpace 关系表
  • 新增后台关系服务、接口、模块注册
  • 新增后台 知识关系 子页与增删改查
  • 同步更新第二阶段文档、数据库归档和变更记录

3. 不纳入范围

本轮不做：运行时 RAG 接线重构、第一阶段桥接层替换、brand/user override 正式化、Provider 独立域。
  • 不重写 KnowledgeBinding
  • 不改现有业务模块运行链路
  • 不进入多品牌与多用户覆盖层生效链路

4. 交付边界

  • 关系表可用
  • 后台治理页可直接使用
  • 数据库优先 / mock 兜底
  • 第一阶段页面与现有业务不受影响

5. 开发原则

  • 以 docs/project_planning 为开发依据
  • 每完成一块，该块功能要可用
  • 同步更新文档、数据库归档、变更记录
  • 完成后执行 prisma generate、前后端 tsc --noEmit 和 diagnostics
