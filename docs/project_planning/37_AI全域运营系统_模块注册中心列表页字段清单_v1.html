AI全域运营系统 模块注册中心列表页字段清单 v1

本清单用于把模块注册中心推进到列表页字段层，指导前端页面开发和后端列表接口返回设计。

1. 页面结构范围

  • 顶部操作区
  • 筛选区
  • 表格列表区

2. P0 表格字段

字段名展示名称来源对象说明
moduleName模块名称ModuleDefinition主展示字段
moduleKey模块标识ModuleDefinition唯一标识
moduleType模块类型ModuleDefinition标签展示
moduleStatus模块状态ModuleDefinition状态标签
entryRoute入口路由ModuleDefinition路由展示
defaultSkillPackageCount默认能力包数聚合字段显示绑定数量
updatedAt最近更新时间审计字段时间文本
P0 目标： 先让用户能快速找到模块、判断状态并进入详情页。

3. 筛选字段

  • searchKeyword：搜索模块名称和标识
  • moduleType：按模块类型筛选
  • moduleStatus：按状态筛选
  • phasePriority：按阶段优先级筛选

4. 列表接口返回草案

建议返回 items、page、pageSize、total、totalPages，列表项至少包含模块名称、标识、类型、状态、路由、默认能力包数和更新时间。
