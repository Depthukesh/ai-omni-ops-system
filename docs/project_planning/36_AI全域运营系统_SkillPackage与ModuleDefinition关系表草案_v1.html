AI全域运营系统 SkillPackage 与 ModuleDefinition 关系表草案 v1

本草案用于把能力包与模块之间的挂载关系落成关系表设计，支撑默认能力包绑定、模块反查能力包和影响范围分析。

1. 关系定位

SkillPackage 与 ModuleDefinition 是多对多关系，因此建议使用独立关系表，而不是把关系全部写死在某一侧的单字段里。

skill_package_modules

2. 关键字段

  • packageId
  • moduleKey
  • bindingType
  • isDefault
  • sortOrder
  • enabled

3. bindingType 建议

  • DEFAULT
  • OPTIONAL
  • SYSTEM_REQUIRED
  • EXPERIMENTAL
P0： 先支持 DEFAULT，再逐步补其他挂载类型。

4. 与模块注册表的关系

ModuleDefinition.defaultSkillPackages 建议继续保留为摘要字段，但真实可查询、可管理、可排序的挂载关系，以 skill_package_modules 为准。

5. 结论

第一阶段最值得尽快落地的，是先把一张干净、可查询、可管理的关系表立起来，这样模块默认能力包绑定和技能中心所属模块展示都会顺很多。
