AI全域运营系统 统一技能中心当前现状与待打通清单 v1

1. 文档目的

本文档用于同步当前统一技能中心、模块、能力包、技能与知识库主线的真实现状，重点说明哪些后台配置已经建立、哪些仍主要停留在后台治理层、哪些链路已经可能影响前端执行，以及哪些关键能力仍未完成闭环。

2. 当前整体判断

  • 后台 模块 / 能力包 / 技能 配置体系已经持续推进，并形成了较完整的治理界面。
  • 前端业务页面对这套新配置体系的消费仍未完全打通。
  • 因此现阶段大量新增配置不会立刻自动影响前端业务页面。
  • 真正已经影响前端执行效果的，仍以旧链路和已接入执行链路的字段为主。

3. 模块、能力包、技能当前状态

3.1 已经建立的后台治理能力

  • 模块注册中心
  • 能力包摘要与技能编排关系
  • 技能专区
  • 提示词绑定
  • 能力包级 References / Scripts 资产治理
  • 技能输入项 first pass 结构化治理

3.2 当前仍主要停留在后台治理层的内容

  • 技能输入项结构化配置
  • 数据库参数真实同步选择
  • 知识库参数真实选择器
  • 技能对能力包资产的继承选择
  • 技能输出区结构化摘要

这些配置当前大多仍通过 SkillConfig.description first pass 持久化，后端尚未拆成正式技能级真源对象和独立数据表，前端业务工作流页也尚未按这套新结构自动渲染输入表单。

3.3 当前已经可能影响前端执行的配置

  • 技能默认模型
  • 技能绑定提示词
  • Prompt 内容本身
  • 既有模块中已经读取技能中心配置的字段

4. 数据库参数当前状态

数据库参数本轮已从静态写死推进到真实同步选择。

  • 植入参数：品牌资料、产品资料、营销策划方案
  • 下拉参数：营销日历、选题库、素材库
  • 复用现有品牌档案、营销日历、选题库、素材库接口
  • 植入参数显示同步数量，下拉参数显示真实可选项，并自动提供“不植入”选项

当前边界是仍未拆成技能级数据库输入真源表，也未形成“技能配置 -> 前端工作流自动出表单”的闭环。

5. 知识库参数当前状态

  • 可先选择知识库
  • 再选择该知识库下已同步的具体内容
  • 默认提供“整库检索”选项
  • 可显示每个知识库当前已同步内容数量

当前边界是还没有真正打通运行时知识检索链路，也没有让技能执行时自动装配知识上下文，更没有把前端业务工作流与知识库做端到端闭环。

因此当前状态是：知识库治理页面和知识库参数选择器已存在，但知识库运行时能力仍未真正建立起来。

6. 当前最核心的未打通项

  1. 技能输入项从 description first pass 升级成正式数据表
  2. 技能级 References / Scripts / Knowledge 绑定真源化
  3. 前端工作流页按技能配置自动生成输入表单
  4. 知识库检索到技能执行的运行时链路打通
  5. 能力包编排配置与真实执行流程对齐

7. 对现有网站运行的影响判断

  • 当前整体影响可控，后台新增治理能力大多不会直接破坏现有前端业务流程。
  • 如果修改到已接入执行链路的模型、Prompt、技能基础配置，仍可能影响生成结果。
  • 后续开发仍需坚持以 docs/project_planning 为依据，并保证每完成一块，该块功能可用。

8. 下一步建议

  1. 技能输入项真源化
  2. 技能知识绑定真源化
  3. 知识库运行时检索链路接入
  4. 前端工作流按技能配置自动渲染输入项
  5. 能力包编排驱动真实执行链路

9. 本轮结论

  • 后台统一技能中心的治理能力继续增强。
  • 数据库参数和知识库参数已经进入真实选择器阶段。
  • 整个系统仍未进入“后台配置一改，前端自动全链路生效”的完成态。
  • 知识库目前仍属于“治理层已建、运行时未闭环”的阶段。
