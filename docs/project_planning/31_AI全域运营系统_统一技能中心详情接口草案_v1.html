AI全域运营系统统一技能中心详情接口草案 v1

本草案用于把统一技能中心详情页字段清单推进到接口层，指导后端详情接口设计和前端详情页数据对接。

1. 主接口建议

GET /api/admin/skill-packages/:packageId

后续如要统一外部标识，也可以补充 GET /api/admin/skill-packages/by-key/:packageKey。

2. 查询参数建议

  • includePrompts、includeProviders、includeVersions 建议第一阶段默认开启
  • includeReferences、includeScripts、includeKnowledge、includeBrandOverrides、includeUserOverrides 可按需懒加载

3. 返回结构草案

export interface SkillPackageDetailResponse {
  package: SkillPackageSummaryDTO;
  skill: SkillDefinitionDTO;
  moduleSummaries: ModuleSummaryDTO[];
  workflowStepSummaries: WorkflowStepSummaryDTO[];
  prompts?: PromptAssetDTO[];
  references?: ReferenceAssetDTO[];
  scripts?: ScriptAssetDTO[];
  knowledgeBindings?: KnowledgeBindingDTO[];
  providerBindings?: ProviderBindingDTO[];
  versions?: SkillPackageVersionDTO[];
  brandOverrides?: BrandSkillPackageOverrideDTO[];
  userOverrides?: UserSkillPackageOverrideDTO[];
}

4. 第一阶段最小返回集合

P0： package、skill、moduleSummaries、prompts、providerBindings、versions

可延后：workflowStepSummaries、references、scripts、knowledgeBindings、brandOverrides、userOverrides。

5. 后续写接口建议

  • PATCH /api/admin/skill-packages/:packageId/basic
  • PATCH /api/admin/skill-packages/:packageId/prompts/:promptId
  • PATCH /api/admin/skill-packages/:packageId/providers/:bindingId
  • POST /api/admin/skill-packages/:packageId/versions
  • POST /api/admin/skill-packages/:packageId/activate-version
