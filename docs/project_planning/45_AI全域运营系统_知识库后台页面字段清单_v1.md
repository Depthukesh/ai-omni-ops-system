# AI全域运营系统 知识库后台页面字段清单 v1

## 1. 文档目的

本文档用于把《知识库主数据层设计草案 v1》进一步落成后台页面字段清单，用于：

- 指导知识库后台页面设计
- 指导前后端字段命名统一
- 指导第一阶段知识库管理页面最小实现范围

## 2. 页面范围

第一阶段建议只覆盖后台管理侧，不改现有前台业务页面。

建议先做以下 4 个页面：

1. 知识空间列表页
2. 知识空间详情页
3. 文档列表页
4. 绑定关系页

## 7. 第一阶段推荐展示集合

### P1

- 同步状态显示

### P2

- 检索日志
- 同步任务详情
- 批量导入与批量绑定

## 8. 页面交互建议

第一阶段建议支持：

- 新建知识空间
- 编辑基础信息
- 查看文档列表
- 新增绑定关系
- 停用和启用空间

第一阶段可延后：

- 批量导入
- 拖拽排序
- 多选批量绑定

## 9. 最终结论

知识库后台页面第一阶段的目标，不是先做成一个很重的知识运营平台，而是先让用户能够：

- 创建空间
- 管理文档
- 建立绑定
- 查看状态

只要这四点跑通，知识库主数据层就已经真正落地。
