AI全域运营系统模块注册规范 v1

本规范用于定义未来新增模块、改造现有模块时必须遵循的统一注册协议，让模块接入从“临时约定”升级为“标准声明”。

注册对象 字段分组 必填规则 枚举建议 注册样例 接入模板

1. 统一注册对象

建议： 定义统一对象 ModuleDefinition，它不代表页面组件，而代表一个可被平台识别、授权、装配、治理的模块单元。

模块注册的核心原则是：先注册，后接入；先定义边界，后开发页面；先声明依赖，后绑定能力；先说明任务与媒体合同，后进入工作流。

2. 字段分组

字段组 推荐字段
基础字段 moduleKey、moduleName、moduleType、moduleStatus、entryRoute、icon、sortOrder、description
权限与可见性 requiredPermissions、featureFlags、isPlatformVisible、isBrandVisible、isAdminVisible
依赖字段 requiredCapabilities、requiredProviders、requiredTables、requiredStorages、requiredThirdPartyPlatforms
执行字段 taskTypes、mediaTypes、workflowTypes、publishTargets
装配字段 defaultSkillPackages、defaultKnowledgeSpaces、defaultProviderPolicies

5. 注册样例

以下是公众号工作台的推荐注册结构：

const wechatWorkbench: ModuleDefinition = {
  moduleKey: "wechat-workbench",
  moduleName: "公众号工作台",
  moduleType: "WORKBENCH",
  moduleStatus: "ACTIVE",
  entryRoute: "/wechat",
  icon: "wechat",
  sortOrder: 40,
  description: "用于公众号文章、图片、HTML 和发布工作流",
  requiredPermissions: ["wechat:workspace:read", "wechat:workspace:write"],
  featureFlags: ["wechat-workbench"],
  isPlatformVisible: true,
  isBrandVisible: true,
  isAdminVisible: true,
  requiredCapabilities: ["copy-domain", "image-domain", "html-render-domain", "publish-domain"],
  requiredProviders: ["text", "image"],
  requiredTables: ["Task", "MediaAsset", "Work"],
  requiredStorages: ["oss"],
  requiredThirdPartyPlatforms: ["wechat-official-account"],
  taskTypes: ["WECHAT_ARTICLE_AI", "WECHAT_IMAGE_AI", "WECHAT_HTML_AI"],
  mediaTypes: ["wechat-cover", "wechat-body-image", "wechat-html"],
  workflowTypes: ["wechat-content-workflow"],
  publishTargets: ["wechat-api"],
  defaultSkillPackages: ["wechat-article-generator", "wechat-image-designer", "wechat-html-renderer"],
  defaultKnowledgeSpaces: ["brand-wechat-knowledge"],
  defaultProviderPolicies: ["brand-wechat-provider-policy"],
};

6. 新模块接入模板

  • 模块身份： 名称、类型、入口是什么
  • 依赖关系： 依赖哪些平台底座、领域能力、Provider、第三方平台
  • 执行合同： 会创建哪些任务、媒体、工作流、发布目标
  • 装配关系： 默认绑定哪些能力包、知识空间、Provider 策略
第一阶段要求： 不必立刻开发完整注册后台，但必须完成字段字典、枚举定义、五个工作台样例和新模块接入模板。
