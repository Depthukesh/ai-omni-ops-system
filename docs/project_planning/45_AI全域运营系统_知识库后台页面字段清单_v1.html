AI全域运营系统 知识库后台页面字段清单 v1

本清单用于定义知识库后台管理页面的字段范围，确保第一阶段先把空间、文档、绑定和状态管理跑通。

1. 页面范围

  • 知识空间列表页
  • 知识空间详情页
  • 文档列表页
  • 绑定关系页
原则： 第一阶段只做后台管理侧页面，不动现有前台业务页面。

2. 知识空间列表页字段

字段名展示名称来源对象优先级
spaceName空间名称KnowledgeSpaceP0
spaceKey空间标识KnowledgeSpaceP0
scope空间范围KnowledgeSpaceP0
status状态KnowledgeSpaceP0
documentCount文档数聚合字段P0
bindingCount绑定数聚合字段P0
updatedAt最近更新时间审计字段P0

3. 知识空间详情页字段

  • spaceName、spaceKey、description
  • scope、status、sourceMode、visibility
  • ownerBrandName、documentStats

第一阶段建议支持 概览、文档、绑定关系 三个页签。

4. 文档与绑定字段

文档列表页： title、sourceType、parseStatus、syncStatus、updatedAt

绑定关系页： bindingType、targetKey、priority、retrievalMode、enabled

5. 结论

知识库后台页面第一阶段的目标，是先让用户能创建空间、管理文档、建立绑定和查看状态，而不是一开始就做成复杂的知识运营平台。
