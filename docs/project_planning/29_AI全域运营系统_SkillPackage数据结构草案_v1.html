AI全域运营系统 SkillPackage 数据结构草案 v1

本草案用于把 SkillPackage 对象关系继续下钻成更贴近实现的数据结构，指导后端对象、数据库拆分和统一技能中心详情接口设计。

1. 建模原则

  • 聚合根： 以 SkillPackage 作为统一根对象
  • 三层结构： 主对象层、资产与绑定层、版本与覆盖层
  • 落地目标： 直接支撑统一技能中心详情页与版本管理

2. 核心对象草案

export interface SkillPackage {
  id: string;
  packageKey: string;
  packageName: string;
  description?: string;
  status: "DRAFT" | "ACTIVE" | "DISABLED" | "ARCHIVED";
  scope: "PLATFORM" | "BRAND" | "USER";
  moduleKeys: string[];
  workflowStepKeys: string[];
  tags: string[];
  currentVersionId?: string;
  defaultKnowledgeSpaceIds: string[];
  defaultProviderPolicyIds: string[];
  createdAt: string;
  updatedAt: string;
}

packageKey 用于唯一标识能力包，scope 用于区分平台默认、品牌覆盖和用户层派生。

3. 子对象建议

  • SkillDefinition：表达能力定义本身与输入输出合同
  • PromptAsset：承载主 Prompt、格式 Prompt、摘要 Prompt 等
  • ReferenceAsset：承载 references 资料
  • ScriptAsset：承载 scripts 与参数说明
  • KnowledgeBinding：承载知识空间绑定和检索优先级
  • ProviderBinding：承载默认 Provider、模型白名单与 fallback

4. 版本与覆盖

export interface SkillPackageVersion {
  id: string;
  packageId: string;
  versionNumber: string;
  changeLog?: string;
  isActive: boolean;
  snapshot: SkillPackageVersionSnapshot;
  createdBy?: string;
  createdAt: string;
}
建议： 版本对象优先保存完整快照，第一阶段先保证可回滚、可对比，再考虑复杂 merge。

覆盖层分为 BrandSkillPackageOverride 与 UserSkillPackageOverride，分别承接品牌级和用户级差异。

5. 详情接口返回草案

export interface SkillPackageDetailDTO {
  package: SkillPackage;
  skill: SkillDefinition;
  prompts: PromptAsset[];
  references: ReferenceAsset[];
  scripts: ScriptAsset[];
  knowledgeBindings: KnowledgeBinding[];
  providerBindings: ProviderBinding[];
  versions: SkillPackageVersion[];
  brandOverrides: BrandSkillPackageOverride[];
  userOverrides: UserSkillPackageOverride[];
}

这份 DTO 可以直接映射概览、Prompt、参考资料、脚本、知识、Provider、版本、品牌覆盖和用户覆盖九个页签。

6. 第一阶段最小集合

P0： SkillPackage、SkillDefinition、PromptAsset、ProviderBinding、SkillPackageVersion

P1： ReferenceAsset、ScriptAsset、模块关联表、工作流步骤关联表

P2： KnowledgeBinding、BrandSkillPackageOverride、UserSkillPackageOverride
