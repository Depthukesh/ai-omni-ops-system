AI全域运营系统能力包模型 v1

本模型用于定义统一技能中心背后的底层对象关系，让 Skill、Prompt、references、scripts、knowledge、Provider 和覆盖规则能落到一个统一聚合模型中。

核心结论 模型层次 对象职责 Skill 与 Prompt 关系 覆盖规则 绑定关系

1. 核心结论

建议： 引入统一聚合根 SkillPackage。它不是简单等于 Skill，而是一个完整能力单元的聚合根，负责串起能力定义、提示词、参考资料、脚本、知识绑定、Provider 绑定和版本状态。

2. 能力包模型的层次

聚合根

  • SkillPackage

子对象

  • Skill
  • PromptAsset
  • ReferenceAsset
  • ScriptAsset
  • KnowledgeBinding
  • ProviderBinding
  • SkillPackageVersion

外部关联对象包括 Brand、User、ModuleDefinition、WorkflowStepDefinition。

3. 各对象职责

对象 职责 建议字段
SkillPackage 能力包聚合根、模块与工作流绑定主对象、版本与状态管理主对象 packageKey、packageName、packageStatus、moduleScope、description、defaultVersionId
Skill 能力定义本身，描述做什么、输出什么、适用于哪里 skillKey、skillName、skillType、inputContract、outputContract
PromptAsset 提示词资产，多版本、激活、回滚、差异对比 promptKey、promptType、content、version、isActive
ReferenceAsset 参考资料与使用说明 referenceKey、referenceTitle、sourcePath、usageNote
ScriptAsset 脚本资产与参数约束 scriptKey、scriptName、scriptType、parameterSchema
KnowledgeBinding 知识空间绑定与检索优先级规则 knowledgeSpaceKey、bindingScope、retrievalPriority、retrievalRule
ProviderBinding 默认 Provider、fallback 与模型白名单策略 providerPolicyKey、bindingMode、fallbackPolicy、modelWhitelist
SkillPackageVersion 能力包版本快照 versionKey、versionNumber、changeSummary、isActive、publishedAt

4. Skill 与 Prompt 的关系模型

重点： Skill 与 Prompt 不能被写死成一一对应关系。
  • 一对一： 简单单步技能
  • 一对多： 一个 Skill 包含主生成 Prompt、摘要 Prompt、标题优化 Prompt、格式整理 Prompt
  • 多对一： 多个 Skill 复用同一通用风格 Prompt 或结构化输出 Prompt

5. 品牌覆盖与用户覆盖规则

  • 平台默认层： 平台默认 SkillPackage、PromptAsset、ProviderBinding
  • 品牌覆盖层： 品牌覆盖 Prompt、Provider、知识绑定
  • 用户覆盖层： 用户级 Prompt 偏好、Provider 偏好、使用偏好
原则：平台定义默认，品牌定义业务差异，用户定义个人偏好。

6. 与模块和工作流的绑定关系

模块绑定

一个模块可绑定多个能力包，一个能力包也可被多个模块复用。

工作流步骤绑定

一个能力包可绑定到一个或多个工作流步骤，因此能力包不仅是配置对象，也是工作流装配对象。
