AI全域运营系统 能力包关系面板填写指引 v1

1. 文档目的

本文档用于说明后台 模块绑定 与 技能绑定 两个面板当前如何填写，尤其是能力包字段现在应该优先怎么选。

2. 当前适用面板

  • 模块绑定：对应模块与能力包关系。
  • 技能绑定：对应能力包与技能关系。

这两个面板当前都已经从“手工录入能力包三元组”升级为“优先使用后台真实能力包选择器，并保留手工填写模式兼容历史值”。

3. 能力包字段填写规则

关系面板中的能力包相关字段包括：

  • packageId
  • packageKey
  • packageName

3.1 优先使用真实选择器

  • 表单顶部新增了 能力包选择。
  • 直接从后台已有 SkillPackage 列表中选择。
  • 选择后会自动带出 packageId、packageKey、packageName。

这是当前推荐方式，可以减少手工录错，并保证关系记录和能力包注册中心里的真实对象一致。在关系面板里，系统还会按当前模块或技能上下文，把更相关的能力包排到前面并标记为推荐。

3.2 保留手工模式

  • 如果历史值还没有进入能力包注册中心。
  • 或者需要兼容旧关系数据。
  • 可以切回 手工填写 / 历史值兼容。

这时仍可以手工填写 packageId、packageKey、packageName。

4. 模块绑定面板填写建议

4.1 关键字段

  • 能力包选择
  • 所属模块
  • 绑定类型
  • 默认挂载
  • 启用状态
  • 排序

4.2 推荐填写顺序

  1. 先选真实能力包。
  2. 再选所属模块。
  3. 再设置 绑定类型。
  4. 最后补 默认挂载、启用状态、排序。

4.3 当前推荐规则

当选择某个模块后，系统会优先推荐 SkillPackage.moduleKeys 中已包含该 moduleKey 的能力包。推荐项会排在选择列表前面，并在表单中显示推荐摘要。

4.4 当前结论

模块绑定面板现在已经不是只靠 packageId / packageKey / packageName 手工录入，当前应优先把模块和真实能力包对象挂上关系。

5. 技能绑定面板填写建议

5.1 关键字段

  • 能力包选择
  • 所属技能
  • 绑定类型
  • 默认挂载
  • 启用状态
  • 排序

5.2 推荐填写顺序

  1. 先选真实能力包。
  2. 再选所属技能。
  3. 再设置 绑定类型。
  4. 最后补 默认挂载、启用状态、排序。

5.3 当前推荐规则

当选择某个技能后，系统会优先参考现有 skillAssetBinding 中该技能已经关联过的 packageKeys。推荐项会排在选择列表前面，并在表单中显示推荐摘要。

5.4 当前结论

技能绑定面板现在也已优先对齐真实能力包对象，后续技能归属、默认能力包和后台治理，应该逐步以这层关系真源为准。

6. 当前总体结论

  • 能力包字段优先走真实选择器。
  • 手工录入仍保留为兼容模式。
  • 已开始支持按模块或技能上下文自动推荐能力包。
  • 能力包注册中心、模块绑定、技能绑定三者的后台治理口径开始统一。

下一步如果继续推进，建议优先做关系面板和模块注册中的 defaultSkillPackages 做更明确的双向对照，并让推荐关系进一步支持自动过滤和一键带出默认绑定。
