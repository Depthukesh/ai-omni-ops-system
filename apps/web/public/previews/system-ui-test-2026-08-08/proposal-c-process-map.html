Business Flow Map

让用户先看懂这套系统怎么运转，再决定去哪个页面执行。

这个方向把首页从“板块目录”重构为“业务流程地图”。首屏直接展示采集、洞察、规划、生产、发布、复盘六个阶段，让系统闭环一眼可见，再把小红书、抖音、公众号、设计页作为各阶段的执行面板挂进去。

关键阻塞 01

适配什么页面

最适合 `brand-growth` 这种跨平台总览页，也适合后续扩展更多平台和多团队协同，因为入口不再依赖平台名称，而依赖实际动作。

对新用户更友好 先理解业务闭环，再进入平台执行页，认知成本更低。
对未来扩展更稳 新增平台时不必改顶层结构，只需挂接到某个阶段。
对当前问题更对症 它直接解决“入口很多，但不知道先做什么”的问题。

为什么比传统后台更清楚

先看到路径 不是先看到平台名称，而是先看到经营动作序列。
再进入执行页 平台页只负责把当前阶段做完，不再同时承担系统说明任务。

最适合改哪些地方
