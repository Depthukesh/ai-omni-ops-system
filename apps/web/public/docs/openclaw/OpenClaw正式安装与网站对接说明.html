OpenClaw 正式安装与网站对接说明

当前口径：安装链路已正式可交付，品牌运营助手 Skill 也已提供正式 ZIP 包；后续仍继续围绕 MCP 闭环迭代。

当前结论

  • 安装中心、品牌令牌、MCP HTTP 网关已经打通。
  • 当前 MCP 已覆盖品牌增长、小红书、抖音、公众号、设计、团队协作、统一素材库、OpenClaw 专区等网站主链路。
  • 品牌运营助手 Skill 已改成“主 Skill + 外部手册”结构，不再只靠一份短文档硬撑全部能力。
  • 反馈分析、提示词优化与完整审计仍在继续补齐，但不影响当前正式安装与交付。

正式交付口径

  • 真正需要安装的是网站 MCP。
  • 安装中心会同时提供正式 Skill ZIP 下载。
  • 正式 Skill 不复制网站功能，而是先路由网站功能，再调用 MCP。

安装片段示例

{
  "mcpServers": {
    "ai-omni-ops-品牌名": {
      "url": "https://你的域名/api/openclaw/mcp",
      "headers": {
        "Authorization": "Bearer ocp_xxx",
        "x-brand-id": "br_xxx"
      },
      "type": "streamableHttp",
      "timeout": 600000
    }
  }
}

Skill ZIP 现在包含什么

  • SKILL.md：主 Skill，负责总规则、路由与高风险边界。
  • README.md：导入说明与验收话术。
  • docs/00-网站功能域地图.md：整站功能域与页面入口。
  • docs/01-MCP工具矩阵.md：当前真实 MCP 工具矩阵。
  • docs/02-高频任务路由手册.md：高频任务如何路由到网站功能与工具链。

当前能力边界

  • 已适合正式安装：查询、生成、工作流推进、发布接力、资料库维护、团队协作、专区归档。
  • 仍以页面承接为主：安全设置、安装中心里的可视化复制动作、后台管理台等纯页面型能力。
  • 仍在补齐：更完整的反馈分析、提示词优化闭环和调用审计。
