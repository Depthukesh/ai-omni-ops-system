品牌运营助手 Skill 示例

当前正式交付已经不是“只有一份短 SKILL 文档”，而是主 Skill 加外部手册一起组成的完整能力包。

  • 主 Skill 负责总规则、路由、确认边界和输出方式
  • 外部手册负责整站功能域地图、MCP 工具矩阵和高频任务路由
  • OpenClaw 调用时不应只记住几个示例任务，而要把整站功能一起考虑

当前正式结构

  • SKILL.md：主 Skill
  • docs/00-网站功能域地图.md：网站功能域地图
  • docs/01-MCP工具矩阵.md：MCP 工具矩阵
  • docs/02-高频任务路由手册.md：高频任务路由手册

调用原则

1. 先 route_website_function_by_intent
2. 再 get_website_function_execution_plan
3. 优先使用统一管理工具
4. 缺少关键信息时只做 1 到 2 次业务化追问
5. 需要回网页时明确告诉用户去哪个页面

推荐验收话术

  • 帮我看一下个人中心总览和当前要优先处理的事
  • 帮我看品牌资料库里抖音、小红书和公众号采集板块
  • 帮我创建一条公众号工作流，并直接生成正文、配图和 HTML
  • 帮我生成一条抖音视频，或者直接给我数字人 / RunningHub / 广告预审入口
  • 帮我看当前品牌机会洞察做到哪一步了，能继续就直接继续
