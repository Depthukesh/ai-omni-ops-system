# 视频号浏览器辅助发布 PoC

该扩展用于验证视频号网页端是否可被浏览器扩展接管，当前只做最小能力验证，不代表已经完成正式发布链路。

## 当前目标

- 验证 `channels.weixin.qq.com` 页面是否可稳定注入扩展
- 验证视频页/图文页是否能识别到上传控件
- 验证标题、正文等输入区域是否可定位
- 验证后续是否值得继续开发正式的视频号发布插件

## 当前能力

- 可安装到 Chrome 或 Edge
- 可在工作台站点响应健康检查和启动指令
- 可自动打开 `https://channels.weixin.qq.com/`
- 可在视频号页面左上角显示 PoC 状态提示
- 可探测页面类型、上传控件数量、标题区/正文区是否命中
- 进入视频发布页后，会尝试自动填写标题和描述
- 如果命中网页端文件上传控件，会继续尝试自动上传视频

## 当前边界

- 当前不会自动点击发表
- 当前不会自动上传图片
- 当前不会和正式视频号工作台打通
- 当前不会创建后端发布会话
- 当前仍处于最小验证阶段，上传是否成功取决于视频号网页端真实控件结构

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录 `wechat-channel-publisher`

## 必须授权的站点

- `http://localhost/*`
- `http://127.0.0.1/*`
- `https://17ai.site/*`
- `https://www.17ai.site/*`
- `https://channels.weixin.qq.com/*`

## 推荐验证步骤

1. 在浏览器里登录 `https://channels.weixin.qq.com/`
2. 确认左上角出现 PoC 提示浮层
3. 手动进入“发表视频”或“发表图文”页面
4. 观察提示是否能更新为“页面已命中”
5. 进入“发表视频”页后，观察左上角浮层与工作台弹窗是否提示已填写文案、已尝试上传视频
