# 小红书草稿发布扩展

## 作用
- 接收 `AI全域运营 -> 小红书 -> 原创笔记 / 二创笔记 -> 一键发布` 发出的桌面发布指令。
- 自动打开小红书创作者中心图文发布页。
- 自动上传图片、填写标题、正文，并点击 `保存草稿`。

## 安装方式
1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启 `开发者模式`。
3. 选择 `加载已解压的扩展程序`。
4. 指向当前目录：

```text
apps/web/public/extensions/xhs-draft-publisher
```

## 使用前提
- 当前浏览器已登录小红书创作者中心。
- 站内小红书作品已经生成完成。
- 本地前端运行在 `3001`，后端运行在 `3011`。

## 当前范围
- 当前只支持 `图文笔记 -> 保存到草稿箱`。
- 不做自动正式发布。
- 手机端自动保存仍作为下一步。

## 已知边界
- 小红书创作者页 DOM 若改版，上传控件或标题/正文选择器可能需要同步更新。
- 首次加载创作者页较慢时，扩展会重试等待内容脚本接管。
