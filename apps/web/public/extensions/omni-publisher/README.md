# AI 全域运营统一发布扩展

该扩展同时支持小红书和抖音的电脑端辅助发布。

## 当前支持

- 小红书：自动打开创作者中心，上传配图并填写标题、正文，保存到草稿箱
- 抖音：自动打开创作者中心上传页，上传视频并填写标题、描述与话题

## 当前边界

- 小红书会自动保存到草稿箱
- 抖音仍需人工确认后点击最终发布
- 浏览器必须已登录对应平台创作者中心

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录 `omni-publisher`
