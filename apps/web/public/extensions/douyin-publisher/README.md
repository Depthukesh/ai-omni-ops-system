# 抖音电脑端辅助发布扩展

该扩展用于接收 AI 全域运营工作台里的“发布到抖音”指令，自动打开抖音创作者中心上传页，上传视频并填写标题、描述与话题。

## 当前能力

- 接收工作台发起的抖音桌面发布会话
- 自动打开 `creator.douyin.com` 上传页
- 自动上传最终视频
- 自动填写标题和描述
- 自动把作品里的 hashtags 追加到描述尾部
- 自动回写“扩展执行成功/失败”状态到工作台

## 当前边界

- 最终“发布”按钮仍需人工确认
- 浏览器必须已登录抖音创作者中心
- 若抖音创作者后台页面结构变化，选择器可能需要更新

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录 `douyin-publisher`

## 必须授权的站点

- `http://localhost/*`
- `http://127.0.0.1/*`
- `https://17ai.site/*`
- `https://www.17ai.site/*`
- `https://creator.douyin.com/*`
