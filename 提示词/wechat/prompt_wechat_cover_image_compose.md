# 公众号封面图生成

基于公众号封面图工作流能力拆分，用于公众号工作流中的“封面图 / 头图”提示词生成阶段。

## 目标

根据文章标题、摘要、品牌调性、主题色、营销节点和账号定位，生成适合公众号 `news` 类型文章的封面图提示词。

## 输入

- 文章标题
- 文章摘要
- 品牌名称 / 品牌调性
- 营销节点
- 产品卖点
- 主题色
- 目标账号名
- 用户指定风格（如高级感、专业感、温暖感、科技感）

## 输出目标

输出的不是图片本身，而是高质量封面图提示词与约束说明，用于后续文生图模型调用。

## 封面图约束

必须同时满足：

- 适合公众号文章头图/封面图使用
- 强调标题主视觉，不要依赖密集小字
- 预留标题安全区
- 适合后续被设置为 `thumb_media_id` 对应的封面主视觉参考
- 风格稳定，不要过度花哨
- 品牌色与内容主题一致

## 提示词应包含的要素

每条 prompt 至少包含：

- 主体对象
- 场景
- 构图
- 光线
- 色彩
- 氛围
- 画面用途：微信公众号封面图 / 头图
- 标题安全区说明

## 输出要求

请输出：

1. `prompt`
2. `visualStyle`
3. `layoutNotes`
4. `negativePrompt`

其中：

- `layoutNotes` 说明标题建议放置区域、留白方向、主体位置
- `negativePrompt` 明确避免乱码文字、低质拼贴、过度 AI 感、手部错误、品牌元素错乱

## 风格规则

- 如果品牌偏专业或 B2B，优先采用编辑感、简洁、可信赖的版式
- 如果品牌偏消费品或生活方式，优先采用温暖、真实、生活化视觉
- 如果营销节点明确，画面要体现活动时令感，但不要堆满元素

## 禁止事项

- 不要生成正文配图 prompt
- 不要输出 API 请求参数
- 不要出现 browser 自动发布步骤
- 不要把封面图做成海报式满版文字
