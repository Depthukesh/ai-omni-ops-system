# Article Posting (文章发表)
## Cover Image Rules
- `news` 类型文章必须带封面图。
- Cover image source priority: CLI `--cover` -> frontmatter (`coverImage` / `featureImage` / `cover` / `image`) -> `imgs/cover.png` -> first inline image.
- If still missing, stop and ask for one.
## Theme Notes
Theme and color are resolved before publishing and should influence visual prompt generation.
