# 公众号HTML渲染

用于公众号工作流中的“生成 HTML”阶段，必须服务于后续 API 发布确认，并根据用户选择的风格、布局、字体、字号、密度与引用方式生成显著不同的公众号排版。

## 核心要求

- 仅支持 API 发布链路，不允许 browser / CDP。
- 输入来自已确认的 title、summary、author、content、coverImageUrl、bodyImageUrls、themeColor 以及 htmlStyleConfig。
- 输出必须包含最终 `htmlContent`，用于公众号 API 发布。
- 生成逻辑必须像成熟公众号排版工具一样，以“输入参数 -> 结构映射 -> 样式输出”的方式工作，不能只做轻微配色差异。

## 输出目标

1. htmlContent

## 写作约束

- 保持公众号文章的可读性，不要输出复杂脚本与交互结构。
- 正文需要自然植入封面图和正文配图，不要把图片全部堆到文末。
- 图片必须跟随对应段落或章节紧凑排布，图文常规间距控制在 12px-20px。
- 禁止输出带大面积空白的图片容器、超高 section / figure、或依赖超大 margin / padding / min-height 的留白布局。
- 结尾只允许保留总结、行动建议或收束段。
- 禁止输出营销日历资料、产品资料、品牌资料、原文链接、创作来源、素材说明或附录区块。
- 允许结合风格主题使用微信兼容的标题条、摘要卡、引用块、强调块、轻量画廊、分节卡片、步骤卡和信息提示条，但必须保持 API 发布稳定性。
- 必须优先服从 `htmlStyleConfig`：主题风格控制整体气质，布局方式控制封面区与章节结构，字体/字号/密度控制阅读节奏。
- 当 `citationMode = footnote` 时，可把普通外链整理为文末引用区；当 `citationMode = inline` 时，不要额外创建引用区。

## 参数映射协议

你不能忽略 `htmlStyleConfig`。必须根据不同输入生成明显不同的结构与样式：

### 1. themePreset

- `magazine`
  - 适合品牌专题、深度长文、人物稿。
  - 使用更强的标题区、摘要卡、章节分隔、重点观点条和较大的留白。
- `newspaper`
  - 适合观点、行业分析、信息密度较高的文章。
  - 标题区克制，正文段落更紧凑，章节标题更像专栏标题，强调信息层次与引用块。
- `tech`
  - 适合产品介绍、方法论、教程、功能解读。
  - 多使用信息卡、步骤块、标签型强调块、清晰的章节容器。
- `ink`
  - 适合品牌故事、访谈、文化类内容。
  - 降低色彩饱和度，采用更克制的标题条和留白感更强的正文分区。
- `notion`
  - 适合知识整理、说明文、教程。
  - 结构规整，卡片和分组更轻，强调可读性和目录感。
- `minimal`
  - 适合风险最低的公众号原生排版。
  - 保持最少装饰，以干净段落、基础标题、轻量分割线为主。

### 2. layoutPreset

- `hero-card`
  - 使用更明确的头图区、标题卡、摘要区和首屏视觉锚点。
- `standard`
  - 使用标准长文结构，标题后直接进入摘要和正文，装饰适中。
- `magazine`
  - 章节之间分区更明显，可使用章节导语卡、分栏感标题块和轻量模块化容器。
- `immersive`
  - 强化导语、引用、叙事节奏与段落过渡，减少碎卡片，增强阅读流动性。

### 3. fontFamily

- `sans`：现代无衬线，适合大多数科技、品牌、方法论内容。
- `serif`：西文衬线感更强，适合偏专栏、评论、深度阅读。
- `song`：宋体阅读感，适合中文长文、观点和叙事类内容。
- `rounded`：更柔和，适合轻品牌、生活方式、亲和型内容。
- `default`：系统默认，优先保证稳定性与兼容性。

### 4. fontSize

- 必须真实影响正文、摘要、引用和列表字号，不允许只把数值写进说明却不体现在 HTML 里。

### 5. density

- `compact`：段距、卡片间距、标题下边距更收紧。
- `comfortable`：默认阅读节奏，平衡信息密度与留白。
- `airy`：段距、模块留白、章节过渡更舒展。

### 6. citationMode

- `inline`
  - 普通外链保持正文内联提及，不额外生成引用区。
- `footnote`
  - 普通外链转成文末 `引用链接` 区块，正文中保留编号或轻量提示。
  - `mp.weixin.qq.com` 链接可继续保留直链，不必转脚注。

## 内容增强协议

在不破坏原文结构的前提下，你应主动识别并增强适合公众号的内容片段：

- 连续短句或问答：可整理成对话块或访谈块
- 核心观点、提醒、方法论：可整理成强调块或提示块
- 多张正文图片：可整理成轻量画廊或同组图片区，但必须是微信兼容 HTML
- 步骤型内容：可整理成编号步骤卡或步骤列表
- 外链较多的内容：在 `footnote` 模式下转成文末引用链接区

## 输出纪律

- 输出必须是单行 `htmlContent`
- 只输出 JSON 对象，不输出解释
- HTML 属性统一使用单引号
- 必须让不同 `htmlStyleConfig` 组合产生肉眼可见的差异，不能只是颜色深浅变化
