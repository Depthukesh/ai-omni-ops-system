# 公众号正文配图生成

基于 `baoyu-post-to-wechat` 的文章发布链路拆分，用于公众号长文中的正文插图、场景图、产品辅助图提示词生成。

## 目标

根据公众号文章结构，为各章节生成适合阅读节奏的正文配图提示词，确保后续插图与正文内容、品牌调性和主题色一致。

## 输入

- 标题
- 摘要
- 正文章节结构
- 每个章节的小标题或主题
- 品牌调性
- 产品卖点
- 主题色
- 用户指定风格

## 输出目标

输出配图规划与每张图的 prompt，而不是最终图片。

## 配图规划要求

正文配图要遵循：

- 服务阅读，不抢主标题
- 一张图对应一个明确段落或章节主题
- 优先生成场景图、产品辅助图、品牌故事图
- 同一篇文章内视觉风格统一
- 避免每张图都做成封面海报感

## 每条配图 prompt 必须包含

- 对应章节名或段落主题
- 画面主体
- 场景描述
- 构图方式
- 色彩与光线
- 品牌调性
- 与前后文关系

## 输出格式

请输出数组 `bodyImagePrompts`，每项包含：

1. `sectionTitle`
2. `imagePurpose`
3. `prompt`
4. `negativePrompt`

其中：

- `imagePurpose` 只能是 `场景图` / `产品辅助图` / `品牌故事图` / `信息转场图`
- `prompt` 需要明确“公众号正文插图”用途
- `negativePrompt` 需要避免低质 AI 纹理、人物畸形、错误文案、杂乱背景

## 数量建议

- 一般生成 2-4 条正文配图提示词
- 如果文章只有一个核心章节，可生成 2 条
- 如果是多章节长文，可生成 3-4 条

## 协同规则

- 与封面图保持统一主题色和品牌风格
- 允许不同章节略有场景变化，但不要风格跳变
- 如果文章中有产品卖点段，至少生成 1 条产品辅助图 prompt
- 如果文章中有品牌故事段，优先补 1 条品牌故事图 prompt

## 禁止事项

- 不生成封面图 prompt
- 不输出 API 发布字段
- 不输出浏览器自动化描述
- 不把每张图都写成宣传海报
