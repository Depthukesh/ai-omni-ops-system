# 数据复盘、运营规划与流量漏斗

## 一、资料来源

本专题主要依据以下资料提炼：

- `016_基本功篇：内容数据复盘以及运营规划`
- `017_进阶篇：流量漏斗思维`
- `第二天2025-08-29（营销+成交”聚焦信任为业务赋能的内容规划4.5小时）`
- `周复盘表 + 数据看板字段表.md`

## 二、复盘不是看播放，而是定位问题发生在哪一层

课程对复盘最重要的启发是：  
不能只看“这条视频火没火”，而要看“这条视频卡死在哪一层”。

漏斗思维可以帮助把问题拆开：

- 曝光有没有拿到
- 停留有没有建立
- 完播有没有撑住
- 互动有没有发生
- 信任有没有形成
- 咨询有没有出现
- 到店有没有推进
- 成交有没有发生

如果不把问题拆开，复盘就只能停留在“这条不行，再拍一条”的低级循环。

## 三、流量漏斗不是单纯平台逻辑，而是经营逻辑

在同城商家场景里，漏斗不能只看到点赞、评论、收藏。  
更重要的是后半段：

- 私信
- 预约
- 到店
- 成交
- 复购
- 转介绍

课程强调，真正有价值的内容，未必播放最大，但往往在后半段更强。  
因此 AI Agent 做复盘时，必须把前端流量和后端经营同时放进去看。

## 四、内容复盘的正确步骤

### 1. 先分层看数据

不要把所有指标混在一起，要至少分成三层：

- 内容层
- 信任层
- 转化层

### 2. 再定位瓶颈

例如：

- 曝光低，可能是题目或同城属性弱
- 停留低，可能是开头无感或切口不对
- 互动低，可能是情绪点不够或讨论点不清
- 咨询低，可能是信任证明不足或 CTA 弱

### 3. 再改动作

复盘如果最后没有落到动作，就不算完成。  
动作要能明确到：

- 下周继续拍什么
- 下周停掉什么
- 下周重写什么

## 五、运营规划的本质是“内容节奏 + 业务节奏”的耦合

课程对运营规划的理解，并不是发内容排期那么简单。  
它强调的是：

- 什么内容在什么阶段发
- 什么内容承担什么业务目标
- 什么内容需要配合活动、直播、到店、承接

因此，规划不是越满越好，而是越能对应经营重点越好。

## 六、周运营规划的建议结构

结合课程与现有模板，可提炼出一个稳定结构：

### 1. 本周重点项目

确定这周的业务主攻方向。

### 2. 本周重点人群

明确这周的主要触达对象。

### 3. 本周重点内容任务

区分：

- 拉新题
- 信任题
- 成交题
- 直播承接题

### 4. 本周重点数据观察点

例如重点看：

- 哪类题更容易进私信
- 哪个 CTA 更容易推进到预约
- 哪类内容更容易被老客评论背书

## 七、AI Agent 应如何使用本专题

调用本专题时，AI Agent 应至少完成以下任务：

- 为内容设定目标层级
- 把每条内容映射到漏斗位置
- 生成日报与周报结构
- 输出问题归因
- 输出下周动作清单

## 八、建议输出物

- 漏斗分层表
- 内容诊断表
- 周复盘结论
- 下周优化动作
- 高表现内容共性总结
- 低表现内容问题归档

## 九、使用提醒

- 不要只看播放量
- 不要把低流量直接等同于低价值
- 不要把评论多误判成转化强
- 不要忽略线索归因和失单原因
- 不要做“只复盘内容、不复盘接待”的假复盘

本专题的最大价值，是帮助 AI Agent 把“内容复盘”升级为“增长复盘”。
