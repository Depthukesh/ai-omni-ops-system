## 二、钩子的本质

课程中的“钩子”不是一句耸动的话，而是观众是否愿意继续给你注意力的第一个理由。  
它解决的核心问题是：

- 为什么观众要停下来
- 为什么观众要继续看
- 为什么观众觉得这条内容和自己有关

钩子如果不成立，后面的骨架、情绪、价值、转化都没有意义。

## 三、钩子最重要的判断标准

一个有效钩子，至少要满足以下三点中的两点：

- 与目标用户强相关
- 有明显反差或问题感
- 能迅速引出一个后果、代价或收益

钩子失败，通常不是因为表达不够花，而是因为：

- 太泛
- 太慢
- 太像废话
- 太像自我介绍

## 四、常见高质量钩子类型

### 1. 问题型钩子

直接点出观众眼前最真实的问题。

适合：

- 咨询型业务
- 决策型内容
- 高频问答型内容

例式：

- 如果你最近正准备___，这条一定先看
- 很多人一开始就卡在___

### 2. 避坑型钩子

强调“做错的代价”，比直接讲正确答案更容易停留。

例式：

- 最容易踩坑的不是___，而是___
- 很多人最后悔的是___

### 3. 反常识型钩子

通过打破默认认知，引发继续观看。

例式：

- 你以为决定___的是___，其实不是
- 大家都在盯着___，真正关键却在___

### 4. 对象点名型钩子

直接说明是说给哪类人听的。

例式：

- 第一次在本地准备装修的人先看
- 预算不高又怕翻车的人，先别急着定

### 5. 场景代入型钩子

通过一个具体生活场景，把观众拉进来。

例式：

- 下班特别累、又不想折腾的时候
- 带孩子周末不知道去哪的时候

### 6. 案例型钩子

直接用真实客户或真实经历引入。

例式：

- 今天来店里的这位客户，一开口我就知道问题在哪了
- 她本来想直接做___，但我第一反应是先别做

## 五、钩子写作的实操原则

### 1. 钩子要尽量短

第一句越长，用户越容易走神。

### 2. 钩子优先说结果或问题

不要先铺垫背景。

### 3. 钩子要有清晰对象

让人一听就知道“是不是说给我听的”。

### 4. 钩子不能只刺激，还要有后续承接

只会吓人、只会夸张、只会吊胃口，但后面内容接不上，会导致掉线。

## 六、同城商家最适合的钩子方向

在同城品牌商家场景里，以下钩子最稳：

- 决策前提醒型
- 适合谁 / 不适合谁型
- 做错代价型
- 本地生活场景型
- 真实客户案例型

因为这些钩子天然更容易连接：

- 咨询
- 到店
- 成交

## 七、AI Agent 调用要求

调用本专题时，AI Agent 应至少输出：

- 3 个候选钩子
- 每个钩子的适用人群
- 每个钩子的切口类型
- 每个钩子后续的承接句
- 最终推荐钩子及推荐原因

## 八、钩子质检清单

- 是否在前三秒内完成
- 是否点明对象或问题
- 是否足够具体
- 是否避免了空话
- 是否能自然进入主体

## 九、使用提醒

- 不要把钩子写成标题党
- 不要为了夸张而失真
- 不要先解释自己是谁
- 不要一上来就卖货

本专题在脚本撰写阶段应被优先调用，因为开头成败会直接决定后续一切内容是否有机会被看见。
