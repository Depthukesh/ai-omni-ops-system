# 账号定位与人设竞争优势

## 一、资料来源

本专题主要依据以下资料提炼：

- `005_方向篇：账号和人设的定位以及竞争优势(上)`
- `006_方向篇：账号和人设的定位以及竞争优势(中)`
- `007_方向篇：账号和人设的定位以及竞争优势(下)`
- `第一天2025-08-28（搭建高商业价值强人设账号体系4小时）`

这些资料共同解决的问题是：  
同一个行业里，为什么有的人账号越来越强，有的人账号越做越像同行的复制品；为什么有的人设能转化，有的人设只能被围观。

## 二、定位不是一句介绍，而是一个完整结构

课程内容反复强调，定位不能只理解成“我是做什么的”。  
真正有效的定位，至少要同时回答五个问题：

- 你服务谁
- 你提供什么价值
- 你为什么值得被信任
- 你与同行相比有什么差异
- 你打算用什么方式被记住

从课程内容里可提炼出一个稳定结构：

`用户 + 价值 + 人设 + 类型 + 风格`

如果只做人设，不做用户和价值，就会变成“有个性，但没业务”；  
如果只做价值，不做人设，就会变成“很专业，但没有记忆点”；  
如果只谈风格，不谈内核，就会变成“看起来好像不一样，但本质没有差异”。

## 三、定位的核心先后顺序

课程强调定位有主次关系，不是五个元素平行重要。  
更合理的顺序是：

1. 先定用户
2. 再定价值
3. 再定人设
4. 最后再定类型与风格

这里最关键的不是“拍什么形式”，而是“为什么要让这类用户持续关注你”。  
如果用户和价值没有定，先讨论拍法、先讨论口播还是呈现、先讨论剪辑风格，都很容易跑偏。

## 四、用户不是泛人群，而是可被击中的那类人

资料中强调，账号定位最容易犯的错，就是用户定得太泛。  
例如：

- 不是“做给所有想变美的人”
- 而是“做给本地想自然改善状态、又怕医美翻车的轻熟龄女性”

- 不是“做给所有装修用户”
- 而是“做给第一次装修、预算有限、最怕后悔的大众家庭”

所以定位中的用户，必须带有：

- 行业身份
- 现实处境
- 决策阶段
- 典型纠结

这样后续的人设、选题、脚本、承接动作才会稳定。

## 五、价值竞争力不是“你会什么”，而是“你比别人为什么更值得选”

课程中对竞争力的强调非常强。  
不是定了一个普通赛道就够了，而是要进一步思考：

- 同样都在讲这个领域，别人为什么要看你
- 同样都在卖这个产品，用户为什么要信你
- 同样都在提供这个服务，你凭什么更有说服力

可提炼出几类常见竞争力来源：

### 1. 专业判断力

你不只是会做，而是更会判断。  
例如：

- 谁适合做，谁不适合做
- 哪种情况该先做，哪种情况不该着急做
- 不同预算下怎么选更稳

### 2. 生命体验

你不是在背知识，而是带着真实经历在表达。  
这种真实经历会增强“人格可信度”。

### 3. 服务标准

让用户感受到你做事更细、更稳、更有流程。

### 4. 审美或风格品位

适用于美学导向行业，例如家居、摄影、服饰、门店空间、生活方式类品牌。

### 5. 价值观吸引

课程中多次提到，有些账号的吸引力不只来自知识，而来自人格与价值观。  
例如对生活的理解、对职业的态度、对用户的真诚方式。

## 六、人设的本质不是自我定义，而是观众印象的综合

课程里一个非常重要的判断是：  
人设不是你嘴里说“我是什么样的人”，而是观众对你形成的总体印象。

这意味着人设不能靠一句简介完成，而是靠长期内容重复强化。

一个有效人设，通常要稳定传递三层信息：

- 你是谁
- 你看待问题的方式是什么
- 你身上最容易被记住的气质是什么

## 七、人设构建的关键抓手

### 1. 稳定价值判断

用户会通过你反复表达的判断，记住你的立场和风格。

### 2. 稳定语言感觉

例如：

- 说话特别直接
- 特别会拆问题
- 特别会安抚焦虑
- 特别有生活感

### 3. 稳定视觉印象

不一定是夸张视觉锤，而是整体呈现一致：

- 穿衣气质
- 出镜状态
- 场景调性
- 内容节奏

### 4. 稳定人物关系与叙事视角

有些账号强，不是因为讲自己，而是因为他总能从一种固定视角看世界。  
这种视角本身就是人设的一部分。

## 八、类型与风格的正确理解

课程后段特别强调：  
类型和风格不是定位的起点，而是内核传达方式。

可以把类型理解为：

- 讲述型
- 呈现型
- 讲述与呈现的混合型

讲述型更偏：

- 解释
- 说理
- 表态
- 拆解

呈现型更偏：

- 画面
- 情境
- 行为
- 对比

对于多数同城商家来说，最稳的方式往往不是走极端，而是：

- 用讲述建立清晰度
- 用呈现建立真实感

## 九、同城品牌商家如何用这部分内容

在同城场景下，这部分资料最适合用于以下任务：

### 1. 定位诊断

判断当前账号是否存在这些问题：

- 用户过泛
- 价值太空
- 人设不稳定
- 差异不足
- 风格先行、内核缺失

### 2. 重做定位句

把“行业说明”升级为“用户 + 价值 + 差异 + 人设”的结构化表达。

### 3. 设计人设关键词

例如：

- 真诚
- 会判断
- 不忽悠
- 有标准
- 有生活感
- 有温度

### 4. 设计主页与前 9 条内容

让用户进入主页后，快速感受到：

- 你讲什么
- 你更适合谁
- 你为什么不一样

## 十、可直接给 AI Agent 的应用要求

调用本专题时，AI Agent 应至少输出：

- 账号定位一句话
- 目标人群描述
- 核心价值描述
- 竞争优势 3-5 条
- 人设关键词 5-8 个
- 信任标签 3-5 个
- 表达类型建议
- 风格建议
- 不建议做的定位方向

## 十一、使用提醒

- 不要让人设脱离业务
- 不要把“会拍”误当成“有定位”
- 不要过早追求花样化风格
- 不要只讲自己，忽视用户场景
- 不要只做个人魅力，不做业务信任

这部分资料的真正价值在于：  
帮助 AI Agent 先把“账号该成为谁”想清楚，再去决定“内容该怎么拍”。
