# 同城品牌商家抖音短视频策划方案技能大纲

## 一、技能定位

本技能以《同城品牌商家抖音短视频获客方法论》为总框架，用于指导 AI Agent 为同城品牌商家生成完整的抖音短视频策划方案、内容策略方案、选题脚本方案、拍摄执行方案、转化承接方案与复盘优化方案。

本技能不是一个“写几条脚本”的轻量工具，而是一套围绕同城商家获客与订单增长的策划型技能。  
它强调：

- 先看懂生意，再做内容
- 先看懂用户，再讲卖点
- 先解决信任，再推动成交
- 先搭系统，再做爆款
- 先全链路，再单点优化

## 三、知识组织方式

为了让技能可调用、可维护、可扩展，本技能把资料拆成两层：

总框架层用于定义整个策划方案的主线流程：

1. 项目定义与诊断
2. 用户洞察与需求拆解
3. 定位与人设设计

7. 拍摄、剪辑与视觉语言
8. 发布、转化、直播、投流
9. 数据复盘与迭代优化

专题引用层用于给不同模块注入更细的知识颗粒度，例如：

## 六、生成原则

本技能生成任何策划方案时，必须同时满足以下要求：

- 框架以总方法论文档为主
- 细节以课程专题文档为证据来源
- 不能只停留在概念层，必须转成动作层
- 必须给出同城商家语境下的落地逻辑
- 必须把内容策划和经营结果关联起来
- 必须体现抖音同城获客、门店转化、信任建立、成交推动、复盘优化的完整链路

## 七、引用策略

调用技能时，应优先遵循以下引用策略：

- 做“定位、人设、竞争优势”时，优先引用 `01` 与 `14`
- 做“选题、内容栏目、内容工作流”时，优先引用 `02`
- 做“脚本、表达、说服力”时，优先引用 `03`、`05`、`06`、`07`、`08`
- 做“故事化、情境化、导演感表达”时，优先引用 `09`、`10`

## 八、最终目标

本技能的最终目标，不是让 AI Agent 写出一份看起来完整的文案，而是让 AI Agent 基于可验证的课程内容和总方法论框架，生成一份真正可以用于同城品牌商家抖音获客、增长和成交的策划方案。
