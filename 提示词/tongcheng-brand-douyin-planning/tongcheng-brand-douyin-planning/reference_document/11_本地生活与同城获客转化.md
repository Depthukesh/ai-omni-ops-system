# 本地生活与同城获客转化

## 一、资料来源

本专题主要依据以下资料提炼：

- `017_进阶篇：流量漏斗思维`
- `第二天2025-08-29（营销+成交”聚焦信任为业务赋能的内容规划4.5小时）`
- 《同城品牌商家抖音短视频获客方法论》中的同城链路章节

## 二、本地生活内容和全国内容的根本差异

本地生活内容最重要的不是泛兴趣，而是“本地高意向”。  
对同城商家来说，平台价值不只是曝光，而是：

- 把附近可能成交的人识别出来
- 提前完成部分信任建立
- 把人推进到评论、私信、预约、到店

因此，同城内容不能照搬全国泛流量打法。

## 三、同城内容的核心任务

### 1. 让本地人知道你

### 2. 让需要你的人感觉“这跟我有关”

### 3. 让用户知道为什么值得来

### 4. 让用户知道现在怎么联系你

## 四、同城商家最重要的内容方向

结合资料，可提炼出四类最关键内容：

### 1. 场景型内容

讲清楚这家店 / 这项服务在什么场景下最适合被需要。

### 2. 体验型内容

让用户感受到：

- 来这里是什么感觉
- 做这项服务是什么感觉
- 和别处有什么差别

### 3. 信任型内容

通过老板、案例、标准、客户反馈降低顾虑。

### 4. 行动型内容

明确引导用户：

- 来店
- 咨询
- 私信
- 直播间提问

## 五、同城转化链路的关键节点

### 1. 刷到

用户在刷内容时，对你的第一印象来自：

- 钩子
- 地域感
- 场景感

### 2. 认可

用户开始判断：

- 你是否靠谱
- 你是否适合他
- 你是否有差异

### 3. 联系

用户进入评论区、私信或直播间。

### 4. 到店 / 预约

进入真实经营链路。

### 5. 成交

内容的任务在这里并没有结束，因为后续还要回收数据做迭代。

## 六、本地生活内容最容易出现的问题

- 只有店面展示，没有用户场景
- 只有活动信息，没有信任铺垫
- 只有好看，没有到店理由
- 只有流量，没有私信承接

## 七、AI Agent 调用要求

调用本专题时，AI Agent 应至少输出：

- 同城获客链路图
- 本地场景切口
- 同城栏目建议
- 到店理由设计
- 评论/私信承接动作

## 八、使用提醒

- 不要把同城内容拍成全国泛流量内容
- 不要忽略本地识别度
- 不要让门店地址和商圈信息完全缺位
- 不要没有承接动作就指望用户自己找上门

本专题是同城商家抖音策划的关键模块，涉及定位、内容、转化、直播承接的完整链路。
