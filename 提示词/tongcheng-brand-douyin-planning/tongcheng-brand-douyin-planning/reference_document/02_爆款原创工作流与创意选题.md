# 爆款原创工作流与创意选题

## 一、资料来源

本专题主要依据以下资料提炼：

- `008_方向篇：常规爆款与原创工作流程`
- `009_方向篇：创意选题的新角度`
- `第三天2025-08-30（“视觉”+“文案”导演思维下的内容生产流程4.5小时）`

这些资料解决的核心问题是：  
内容不是随机想出来的，而是可以被持续生产、持续迭代、持续优化的工作流。

## 二、爆款不是玄学，而是“相关性 + 结构 + 供给效率”

课程里对爆款的理解并不神秘。  
一个内容能起量，往往不是因为“碰巧”，而是因为同时满足了几件事：

- 对用户足够相关
- 有足够明确的情绪或认知切口
- 结构足够利于传播
- 表达足够清晰
- 供给速度足够跟上

因此，不应把选题理解为“灵感瞬间”，而要把它理解为一种可被系统化收集与筛选的工作。

## 三、常规爆款与原创内容不是对立关系

课程强调，原创不是脱离规律的自我表达，常规爆款也不是简单照抄。

更合理的理解是：

- 常规爆款负责帮助你理解平台已有验证过的关注机制
- 原创负责帮助你形成自己的长期表达资产

如果只做常规爆款，账号会缺少自己的辨识度；  
如果只做原创但完全不顾用户停留逻辑，账号很容易陷入自我欣赏。

正确做法是：

- 先研究已有爆款为什么成立
- 再把它转化成适合自己业务、适合自己人设、适合自己用户的内容

## 四、内容工作流的核心步骤

结合资料，可提炼出一条稳定的内容工作流：

1. 明确方向
2. 收集素材
3. 提炼问题
4. 寻找切口
5. 转成选题
6. 选择表现形式
7. 进入脚本与执行

其中真正决定质量差异的，不是最后“拍得好不好”，而是中间这几个环节：

- 你从哪里拿素材
- 你怎么理解用户问题
- 你怎么找到新角度

## 五、创意选题的新角度，本质是“换一个更能被感知的入口”

资料中对于选题的新角度，强调的并不是天马行空，而是：

- 同样的问题，换一个更具体的场景讲
- 同样的知识，换一个更有冲突的入口讲
- 同样的产品，换一个更贴近用户体验的语言讲

例如不要直接讲：

- 怎么做装修
- 怎么选门窗
- 怎么变美

而要转换成：

- 第一次装修最容易后悔的一笔钱到底在哪
- 住进去三个月才发现后悔的门窗问题是什么
- 很多人不是不会变好看，而是一开始方向就错了

## 六、选题切口的常见来源

### 1. 用户问题

最直接，也最适合转化。  
例如评论区、私信、门店咨询中反复出现的问题。

### 2. 用户误区

适合起停留，也适合建立专业判断力。

### 3. 场景变化

节日、天气、时间段、人生节点、消费节点，都可以成为切口。

### 4. 对比关系

当用户不会判断差异时，对比最容易让人停下来。

### 5. 代价与后果

比起抽象正确答案，很多人更容易被“做错之后的代价”触发。

### 6. 真实经历

课程里反复强调生命体验与私人经验的重要性。  
选题如果只有行业共识，没有个人经历，很容易普通。

## 七、选题并不是越多越好，而是越能形成系统越好

资料强调内容生产不要只是零散创作，而要形成连续性。  
因此，选题最好按模块管理：

- 获客题
- 信任题
- 成交题
- 案例题
- 生活化题
- 直播承接题

当一个账号有持续供给能力时，用户对账号的判断会更稳定，转化也更容易形成。

## 八、选题的筛选标准

课程内容可以转译成以下筛选规则：

### 1. 是否与目标用户高度相关

### 2. 是否具备清晰切口

### 3. 是否能形成强感知

### 4. 是否适合当前账号阶段

### 5. 是否能和业务承接相连

### 6. 是否具备较低执行摩擦

很多时候，不是题目不好，而是当前团队拍不出来、接不住、承接不了。

## 九、从“方向”到“周选题池”的转化方法

AI Agent 调用本专题时，不应只给零散题目，而要按以下结构产出：

### 第一步：确认本周经营重点

- 是要拉新
- 还是建信任
- 还是推转化
- 还是为直播预热

### 第二步：围绕重点项目与重点人群建池

例如：

- 一个项目至少出 5-10 个题
- 同一人群至少从“问题、误区、场景、对比、案例”五个角度切

### 第三步：用优先级排布

- A 类：本周必须拍
- B 类：本周可拍
- C 类：保留观察

## 十、适合 AI Agent 的应用方式

本专题最适合在以下任务中调用：

- 生成周选题池
- 生成月度内容方向
- 生成栏目规划
- 生成爆款复写方向
- 生成原创差异化切口

调用后，AI Agent 应至少输出：

- 核心方向
- 目标人群
- 本周经营目标
- 20-30 个备选题
- 8-10 个优先题
- 每个题的切口解释
- 每个题对应的业务作用

## 十一、使用提醒

- 不要把“追热点”当作主要选题方法
- 不要只追求新奇，忽略相关性
- 不要把选题和业务割裂
- 不要只看流量，不看咨询和成交
- 不要让选题成为孤立动作，要放进内容系统里

这部分资料最重要的价值在于：  
帮助 AI Agent 从“给我几个题目”升级为“为同城商家建立可持续的内容供给系统”。
